# @ap/menu-admin 변경 기록

내부 버전이며 발행하지 않는다. SDK 범위는 package.json의 ap.sdk를 따른다.

## 0.2.0 — 2026-11-01

- 변경 감사·권한/역할의 왼쪽 필터 패널이 없어진다. 조건은 표 위 필터 줄(고정 버튼 + 「+ 필터」)과 머리글 깔때기로 건다: 감사는 작업·행위자(고정), 출처·시각 범위·대상 유형·대상 ID, 권한/역할은 역할·권한(고정). 조건은 주소에 보이지 않고 하나의 `filter` 키로 다룬다.
- 옛 링크(`actor`·`type`·`action`·`source`·`fromAt`·`toAt`·`targetId`, `role`·`permission`)는 한 릴리스 동안 같은 결과를 보이고 열자마자 주소에서 사라진다. 시각 범위는 분 단위로 고른다(옛 칸의 초 단위 입력은 없어진다. 링크로 들어온 초 단위 값은 편집하지 않는 한 그대로 쓴다). 서버 포트는 그대로다 (#1217).

## 0.1.3 — 2026-10-31

- 변경 감사·활용률·메뉴 레지스트리의 표 제목을 개요 전용(sr-only)으로 가리고, 레지스트리의 긴 선언 셀(ID·Path·Context·페이지 키·리셋 키)은 한 줄에 생략해 전체 값을 title로 보여준다 (#1167).

## 0.1.2 — 2026-10-31

- AuditTrail: 부제에서 "합성 감사 이벤트입니다." 문장을 뺀다. 실제 서버에서도 같은 화면이라 어댑터에 따라 틀린 안내가 된다(#1159).

## 0.1.1 — 2026-10-29

- AuditTrail: 대상 유형 필터가 불투명 토큰을 받는다(실제 18종 + 견본 3종 표시 이름, 형식 맞는 미지 유형은 원문 선택지로 유지, #1091, ADR-0101).

## 0.1.0 — 2026-10-27

- 초기 기록: AccessDirectory, AuditTrail, UsageOverview, RegistryCatalog.
