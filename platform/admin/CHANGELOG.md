# @ap/menu-admin 변경 기록

내부 버전이며 발행하지 않는다. SDK 범위는 package.json의 ap.sdk를 따른다.

## 0.2.2 — 2026-11-02

- 변경 감사의 `type`·`actor`·`action`·`source`·`fromAt`·`toAt`·`targetId`, 권한/역할의 `role`·`permission` URL 별칭을 제거했다. 필터는 반복·숨은 `filter` 키를 쓴다. 옛 키는 조건으로 적용하지 않고 경고 없이 주소에 남긴다 (#1246, ADR-0105).

## 0.2.1 — 2026-11-01

- 변경 감사의 시각은 다시 초 단위로 고르고, 보는 사람의 시간대로 읽고 쓴다. 그 시간대에 없는 시각(서머타임 gap)이나 두 번 있는 시각(fold)은 편집기에서 사유와 함께 거절한다. 시작이 끝보다 앞서지 않는 범위, 공백·특수문자가 든 행위자·대상 유형·대상 ID·역할, 목록에 없는 작업·출처·권한은 새 `filter` 링크로 들어와도 옛 링크와 같이 경고와 초기화를 보이고 조회하지 않는다. 편집기에서도 같은 사유로 적용이 막힌다.
- 권한/역할의 「모두 지우기」와 빈 결과의 「필터 초기화」가 열려 있던 상세(`focus`/`tab`)도 함께 닫는다.
- 내부: 옛 페이지 키 해석 코드(`parseAuditKeys`·`parseAccessKeys` 등)와 시각 변환은 SDK로 옮기거나 지웠다 (#1217).

## 0.2.0 — 2026-11-01

- 변경 감사·권한/역할의 왼쪽 필터 패널이 없어진다. 조건은 표 위 필터 줄(고정 버튼 + 「+ 필터」)과 머리글 깔때기로 건다: 감사는 작업·행위자(고정), 출처·시각 범위·대상 유형·대상 ID, 권한/역할은 역할·권한(고정). 조건은 주소에 보이지 않고 하나의 `filter` 키로 다룬다.
- 옛 링크(`actor`·`type`·`action`·`source`·`fromAt`·`toAt`·`targetId`, `role`·`permission`)는 한 릴리스 동안 같은 결과를 보이고 열자마자 주소에서 사라진다. 서버 포트는 그대로다 (#1217).

## 0.1.3 — 2026-10-31

- 변경 감사·활용률·메뉴 레지스트리의 표 제목을 개요 전용(sr-only)으로 가리고, 레지스트리의 긴 선언 셀(ID·Path·Context·페이지 키·리셋 키)은 한 줄에 생략해 전체 값을 title로 보여준다 (#1167).

## 0.1.2 — 2026-10-31

- AuditTrail: 부제에서 "합성 감사 이벤트입니다." 문장을 뺀다. 실제 서버에서도 같은 화면이라 어댑터에 따라 틀린 안내가 된다(#1159).

## 0.1.1 — 2026-10-29

- AuditTrail: 대상 유형 필터가 불투명 토큰을 받는다(실제 18종 + 견본 3종 표시 이름, 형식 맞는 미지 유형은 원문 선택지로 유지, #1091, ADR-0101).

## 0.1.0 — 2026-10-27

- 초기 기록: AccessDirectory, AuditTrail, UsageOverview, RegistryCatalog.
