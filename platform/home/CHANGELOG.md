# @ap/menu-home 변경 기록

내부 버전이며 발행하지 않는다. SDK 범위는 package.json의 ap.sdk를 따른다.

## 0.2.1 — 2026-10-31

- 홈 두 격자가 뷰포트가 아니라 페이지 본문 컨테이너 쿼리로 열 수를 정하고, 카드 설명이 단어 경계에서 줄바꿈한다 (#1167).

## 0.2.0 — 2026-10-30

- 앱 전용 `./launcher` 설정으로 승인된 A 그룹 타일을 조립한다. 권한·진입/이어서 주소와 기본 manifest의 라벨 없는 격자는 유지한다 (#1109, ADR-0102).

## 0.1.2 — 2026-10-30

- 업무 시스템이 0개일 때 홈 안내 문구를 권한 요청 화면의 실제 동작(업무 시스템 접근 권한은 플랫폼 관리자가 부여, 이 화면은 기능 권한 요청)에 맞게 고침 (#740).

## 0.1.1 — 2026-10-29

- 공지 닫기 버튼의 접근 이름을 실제 동작(이번 방문 동안만 닫힘, 새로고침하면 다시 표시)에 맞게 고침 (#1139).
