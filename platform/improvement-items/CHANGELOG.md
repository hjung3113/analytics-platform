# @ap/menu-improvement-items 변경 기록

내부 버전이며 발행하지 않는다. SDK 범위는 package.json의 ap.sdk를 따른다.

## 0.1.12 — 2026-11-14

- 벽시계 표시 함수 공통화 및 메뉴 소유 쓰기 표본 등록 (#2010).

## 0.1.11 — 2026-11-14

- 화면 설명을 개조식으로 통일하고 관련 사용자 문구·예시 값을 정리 (#1997).

## 0.1.10 — 2026-11-14

- 출처·이력·비교 링크의 room 권한을 확인하고 알 수 없는 Site를 가린다. 상세 제한 안내에 Site 미확인·공정 범위 밖 가능성을 표시하고, 저장된 비교 링크만 범위 밖이면 그 링크만 열 수 없다고 따로 안내하고, viewer 검토용 제한 행을 추가(#2076).
- 로그인 전원 읽기를 유지하면서 Scope 밖 대상·분석 출처·효과 비교 링크를 서버와 mock 응답에서 가리고 `권한 밖`으로 표시(#2076).

## 0.1.9 — 2026-11-14

- 화면이 마운트된 채 사이드바로 `개선 아이템`에 다시 들어와도 `내 담당` 보기의 필터를 다시 넣는다. 한 번만 넣던 초기화 대신 주소 상태(`view`가 없거나 `all`이 아니고 `filter`가 비었음)를 볼 때마다 `replace`로 쓴다. 지운 조건(`view=all`)과 `view`·`filter`를 명시한 딥링크는 그대로 둔다(#2012).

## 0.1.8 — 2026-11-10

- Quest 조회(`getQuest`·`searchQuests`)를 `PlatformAdapter` 포트에서 메뉴 조회 `improvement.quest`·`improvement.questSearch`로 옮겼다. `QuestReference`는 `useMenuQuery`, 선택기의 ID 확인은 `useMenuFetch`를 쓰고, mock 처리기는 `src/mock/`에 있다. 아이템 쓰기는 Quest 조회를 다시 읽지 않는다(#1641, ADR-0134).

## 0.1.7 — 2026-11-07

- 대상 제안이 메뉴가 선언한 `subjectPageKeys`만 읽고 `drillEquipment` 하드코딩을 지웠다. 선언이 없으면 Selection으로 제안한다(#1430 Q3).

## 0.1.6 — 2026-11-07

- 대상 종류 표시와 같은 이름·키의 중복 제거, 생성 서랍의 대상 목록·추가 입력을 조치와 Quest 사이 한 섹션으로 통합(#1430 UX-5·UX-6). 만들기 서랍의 같은 메뉴 뒤로·앞으로와 상태 이동 대화상자 닫기가 입력을 확인하고, `originPage`를 주소창에서 숨기며 옛 출처 page 분기를 지웠다. mock의 잘못된 타입 응답은 서버처럼 `required`다(UX-1·UX-4, Q1·Q2·Q4).

## 0.1.5 — 2026-11-07

- 분석 머리 ⋯의 슬롯 진입점, 분리된 originPage 출처 복원, UTF-8 8KiB 검사·초안 복구, Quest 위 대상 제안과 결과 내부 스크롤.

## 0.1.4 — 2026-11-07

- 확정된 Context → 문제 → 조치 → Quest 생성 서랍, 제거 가능한 설비 대상 제안·종류별 입력 도움말, Registry·카탈로그 출처 이름과 저장된 페이지 키 복원.

## 0.1.3 — 2026-11-06

- 조치일 전후 기간·분석 Context 비교 링크, 선택한 링크와 효과 확인 결과·메모 저장 및 읽기 전용 재열기.

## 0.1.2 — 2026-11-05

- 홈 담당 카드 링크의 접근 가능한 이름에 표시 문구·건수 유지, 44px 이상 너비 전체 링크와 144px 고정 높이의 밀도 개선.

## 0.1.1 — 2026-11-05

- 홈 슬롯의 내 담당 개선 아이템 카드: 미종결 담당 건수·효과 확인 대기 건수, 저장된 보기 링크, 로딩·오류 재시도·0건·권한 제한, 한국어·영어.

## 0.1.0 — 2026-11-05

- 직속 개선 아이템 목록·상세·Context 우선 만들기 서랍(A안), 저장된 보기·표 필터·상태 확인 및 version 충돌 복구.
- 과제(Quest) 읽기/선택 실패 복구, 대상별 적용 이력, 미구현 효과 비교 영역.
- menu-query 읽기 3종·menu-action 쓰기 6종 미러와 결정적인 mock/CAS, 단위·컴포넌트 검사.
