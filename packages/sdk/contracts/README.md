# @ap/contracts

플랫폼, 서버, 메뉴가 함께 쓰는 계약 타입과 순수 함수입니다. 런타임 환경(React, DOM)에 기대지 않아서 서버 쪽에서도 같은 타입을 쓸 수 있습니다.

- **들어 있는 것:** 어댑터 포트, 메뉴 조회 선언(`defineEndpoint`), 메뉴·그룹·공간·권한 id 타입, 기간·시간 계산, 저장된 뷰 타입
- **공개 진입점:** `.`(타입과 함수), `./build`(빌드 도구: 메뉴 선언 스냅샷 방출기·Vite 플러그인), `./vocab.json`(닫힌 어휘 목록)
- **의존 방향:** 가장 아래 층입니다. 다른 `@ap/*`를 import하지 않습니다.
- **쓰기 전에:** 이 저장소 밖 소비자용 안내는 아직 없습니다. 저장소 안에서는 아래 문서를 봅니다.

처음이면 [첫 메뉴 화면 만들기](../../../docs/guides/first-menu-screen.md)부터 읽습니다. 파일별 설명과 작업 규칙은 [AGENTS.md](AGENTS.md), 계약 원본은 [06 플랫폼 계약](../../../docs/contract/platform-ui-contract.md)입니다.
