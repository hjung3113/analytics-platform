# 멀티 워크스페이스 v2 시안

사용자가 2026-10-08에 승인한 클릭형 HTML 시안이다([#249](https://github.com/hjung3113/analytics-platform/issues/249), [ADR-0026](../../adr/0026-multi-workspace-app-boundaries-and-feedbackops-scoping.md)). 설계 문서는 [15](../../15_multi_workspace_ui.md)다.

## 보는 법

[`index.html`](index.html)을 브라우저로 직접 연다. 빌드나 서버가 필요 없고 외부 스크립트를 부르지 않는다.

- 홈(시스템 런처)에서 업무 시스템을 고른다. 레일 버튼으로 시스템을 바꾸면 사이드바가 그 시스템 것으로 통째로 바뀐다.
- 사이드바 아래 VOC·Task·설문은 현재 시스템으로 좁힌 협업 진입이다. 전체 협업 허브는 레일에서 따로 연다. 실제 앱에서는 둘 다 FeedbackOps를 새 탭으로 여는 링크다([ADR-0027](../../adr/0027-feedbackops-stays-standalone-entry-links.md)).
- 검색(Ctrl+K)은 모든 시스템의 메뉴를 찾고 결과에 시스템명을 붙인다.

## 실제 앱과 다른 점

시안은 방향 승인용 모의 화면이다. 구현 정본이 아니며 차이는 [15 §9](../../15_multi_workspace_ui.md#9-프로토타입과-실제-구현의-차이)에 정리했다. 요약:

- 치수: 시안의 레일 56px·사이드바 252px·상단 바 56px 대신 실제 앱 계약(레일 52px, 사이드바 240/56px, 상단 바 없음 + 페이지 머리 50px, 06 §7)을 따른다.
- 데이터·권한: 샘플 배열, 모두 접근 가능한 샘플 사용자, 브라우저 메모리의 최근·복귀 상태다. 실제로는 FeedbackOps API·서버 권한·SSO·URL 계약을 쓴다.
- 협력사 검토의 CSV 버튼은 모의 동작이다. 구현 후보는 XLSX 내보내기이고 보안메일 연동은 범위 밖이다.
- 설비·모델·지표 값은 가상 값이다.

셸을 바꾸는 코드 작업은 이 시안이 아니라 실제 앱 위 `?variant=` 시안으로 다시 컨펌받는다(루트 `AGENTS.md`).
