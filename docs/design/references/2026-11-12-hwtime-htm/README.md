# HW Time × HTM UX concept references (2026-11-12)

Status: **Design Candidate / On-hold / Not approved for implementation**.

These four images were generated for UX discussion, not captured from the actual application. All labels, measurements, counts, thresholds, people, and model/equipment IDs are fictitious. Apparent HTM comparisons in these images are conceptual only; no real HTM data contract or evaluation backend has been verified.

- [Guided drill](./drill.png) — Module → Motion breakdown, threshold badges, detail pane.
- [Comparison](./compare.png) — selected equipment/Module/Motion and HTM reference lines.

Do not read these mockups as an ADR, implementation spec, confirmed standard-key granularity, status mapping, dataset definition, or approved shell redesign.

The navigation/theme exploration belongs to #1758/#1760 and a separate shell UX candidate issue, **not** to the HW Time menu implementation. The menu implementation reuses existing SDK components wherever possible and awaits review of ADR-0078 before replacing the four registered menus with in-menu views.
