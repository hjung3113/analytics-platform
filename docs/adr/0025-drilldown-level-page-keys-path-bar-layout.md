# 드릴다운은 단계마다 page key 하나, Context가 바뀌면 지우고, 경로 바 + 단계마다 본문 교체로 보인다

상태: **Decided (2026-10-08)**.
- 결정자: 사용자 — #225 설계 초안([14](../14_drilldown_platform.md))의 두 질문에 권장안을 골랐다("단계마다 키 하나", "지운다"). 이어서 실제 앱 위 `?variant=` 시안(브랜치 `hjung3113/proto-225-drill-layout`) A/B/C 중 A를 골랐다.

메뉴가 단계별로 좁혀 들어가는 화면(예: 공정 → StGroup → 설비)을 직접 만들지 않고 플랫폼 기능과 레이아웃으로 조립하게 한다(#225). 리서치(Power BI·Superset·Sisense·SAP Fiori·Carbon·PatternFly·Grafana)에서 공통으로 나온 함정은 세 가지다. 단계 상태를 URL 밖에 두면 링크로 공유할 수 없다. 앞 단계를 바꾸고도 뒤 단계를 남기면 모순된 경로가 생긴다. 메뉴 위치(breadcrumb), 단계 경로, 이동 기록(돌아가기)을 한 요소에 섞으면 무엇을 누르면 어디로 가는지 알 수 없다. 계약의 원본은 [06](../06_platform_ui_contract.md) §6.4(URL)·§12.7(레이아웃)·§22(메뉴 간 복귀)다.

## 결정

- **URL**: 단계마다 메뉴가 등록한 page key 하나(예: `drillRoom=PHOTO&drillStgroup=STG-PHOTO-A`). 메뉴 manifest가 단계 순서를 선언하고, 새 단계로 들어가기·올라가기·같은 단계의 다른 값으로 바꾸기는 history push다. 올라가거나 바꾸면 그 뒤 단계 키를 모두 지운다.
- **전역 Context 변경**: 사용자가 Context 바(기간·room_name·조건 등)를 바꾸면 단계 키를 모두 지운다. 단계 값은 그 조건의 결과에서 고른 값이라 표 페이지 번호와 같은 `contextResetKeys` 규칙을 따른다. 뒤로/앞으로 가기와 URL 진입은 지우지 않는다.
- **레이아웃**: 경로 바(`전체 › 공정: PHOTO › StGroup: STG-PHOTO-A`)를 두고 단계마다 본문을 통째로 바꾼다. 마지막 단계(객체 하나)는 오른쪽 상세 슬롯(ADR-0013)으로 연다. 경로 칩의 ▾로 같은 단계의 다른 값으로 바로 바꾼다.

## Considered Options

URL:
- **(채택) 단계마다 키 하나**: 지금 URL 규칙(키마다 값 하나, 메뉴가 키 등록, `safeReturnTo`가 `pageKeys`로 파싱)을 그대로 쓴다. 사람이 읽을 수 있다(Grafana `var-x`).
- **예약 키 하나에 묶기**(`drill=room:PHOTO,stgroup:STG-PHOTO-A`): 메뉴가 등록할 키는 늘지 않지만 값 안에 새 문법이 생겨 검증 규칙을 따로 만들어야 한다.

Context 변경:
- **(채택) 지운다**: `contextResetKeys`와 같은 규칙이라 새 장치가 없다.
- **남기고 다시 검증**: 기간만 바꿔 같은 설비를 계속 볼 수 있지만, 새 조건에 그 값이 없으면 "없는 값" 거부 화면이 자주 뜬다.

레이아웃(시안 비교):
- **(A, 채택) 경로 바 + 본문 교체**: 단계마다 표가 화면 폭을 다 쓰고, 오른쪽 상세가 열려도 표가 찌그러지지 않는다. 요약이 사라지는 대신 "전체" 칩으로 돌아간다.
- **(B) 2–3열 나란히**(SAP Fiori Flexible Column Layout): 형제 사이를 빨리 오가지만 열이 좁아 값과 점유율만 들어가고, 상세까지 열면 비좁다.
- **(C) 아래로 쌓는 섹션**: 요약과 현재 단계를 함께 보지만 깊어지면 스크롤이 길고, 상세가 열리면 위쪽 표가 찌그러졌다.

## 결과

- Kernel이 단계 선언 검증·단계 상태 읽기·들어가기/올라가기와 복귀 출처(출발 메뉴 이름과 단계)를 제공하고, 공통 컴포넌트가 경로 바·드릴 레이아웃·복귀 버튼을 제공한다. 견본 소비자는 생산성 개요(공정 → StGroup → 설비)와 설비 상세·실행 상세의 복귀 버튼이다.
- 시안 코드는 본 코드에 넣지 않는다. 단계 이동의 활용률 계측(ADR-0020)과 깊이 4 초과는 미룬다.
