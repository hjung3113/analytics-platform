# 차트는 ECharts Canvas 렌더러를 쓴다

상태: **Decided (2026-10-05)**.
- 결정자: 사용자 — 에이전트 추천을 따랐다("나머지도 니추천대로 진행"). 2026-09-25 프론트엔드 스택 결정의 "ECharts (SVG 렌더러)"를 대체한다.

스택 표의 원본은 [04 프론트 기술 스택](../04_frontend_ui_ux.md), 차트 계약은 [06 §16](../06_platform_ui_contract.md#16-analysis-chart-contract)이다. 이 ADR은 결정과 이유만 둔다.

2026-09-25 스택 결정은 ECharts를 SVG 렌더러로 적었다. 근거는 Unit B 프로토타입(`prototypes/kernel-chart-frame/`)이 테스트에서 SVG SSR 렌더링을 검증했다는 것이었다. 통합 앱은 처음부터 Canvas 렌더러로 출시됐고(`packages/components/src/EChartImpl.tsx`, 별도 지연 청크 #48), 문서와 코드가 어긋난 채 남아 있었다.

## 결정

- 플랫폼 차트는 ECharts Canvas 렌더러를 쓴다. 문서를 코드에 맞춘다.
- 접근성은 렌더러에 기대지 않는다: 차트 제목·단위, 선택 구간 텍스트 요약, 같은 데이터의 상세 표, 키보드 구간 선택, 색 외 선 형태(04, 06 §16, ADR-0014).

## Considered Options

- **(A) 코드를 SVG로 바꾼다**: 텍스트가 DOM 폰트를 따라가고 벡터 출력이 쉽다. 하지만 이 앱은 데스크톱 전용 SPA라 SSR이 필요 없고, 바꾸면 선 대비·패턴·범례(ADR-0012·0014)와 차트 E2E를 다시 검증해야 한다.
- **(B, 채택) Canvas를 유지하고 문서를 맞춘다**: 시계열처럼 점이 많은 차트에 유리하고, 이미 출시·검증된 상태다. 차트 내보내기는 CSV라 렌더러와 무관하다. 대가: 동적 서브셋 폰트 글리프가 첫 그리기 뒤에 도착하면 그 차트는 대체 폰트로 남는다(`EChart.tsx` 주석, 허용).

## 결과

- 04 스택 표의 차트 행과 05의 "코드와 다른 곳"에서 ECharts 렌더러를 결정 대기에서 뺀다.
- 벡터 인쇄·SVG 내보내기나 작은 차트를 수십 개 띄우는 화면이 필요해지면 다시 본다.
