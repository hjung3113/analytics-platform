# 그리드 편의 기능은 무료 경로로 먼저 적용하고, 표 엔진은 메뉴에 드러내지 않는다

상태: **Decided (2026-10-02)**.
- 사용자 결정: 무료로 시작하고 필요성이 확인되면 유료로 전환하는 방침, 그리고 이번 범위(#159 — 아래 결정).
- 플랫폼 결정: 표 엔진을 메뉴에서 감추는 것(#160에서 구현) — 위 방침을 싸게 지키기 위한 것.

후보별 판정·근거·출처, 유료 전환 계획의 세부는 [04 그리드·차트·데이터 도구 검토](../04_frontend_ui_ux.md#그리드차트데이터-도구-검토-2026-10-02)가 소유한다. 이 ADR은 결정과 이유만 둔다.

분석 화면 사용자는 "엑셀 수준의 그리드 편의성"을 원한다. 그 핵심 기능(셀 범위 선택·여러 셀 복붙·채우기·사용자 피벗·XLSX)은 대표 후보 AG Grid에서 유료(Enterprise)이고, 어느 기능이 업무 필수인지는 실제 사내 메뉴로 아직 확인되지 않았다. 지금 `PlatformDataTable`(TanStack Table + Virtual, MIT)은 06 §15 기본 기능을 갖췄다.

**결정(#159, 사용자):** 행 복사와 전체 결과 XLSX를 무료 경로로 먼저 적용한다(#172 프로토타입 → #173 · #174). 자유 피벗(#163)과 셀 범위 복붙·채우기(#164)는 이슈로 남겨 보류하고, 업무 필수로 확인될 때 재개한다. 붙여넣기 대량 편집은 그리드와 별개로 쓰기 계약(메뉴 선언 쓰기 엔드포인트·서버 검증·권한·감사)이 먼저라 이번 범위가 아니다. 셀 수식은 공식 지표가 서버 계산이라 채택하지 않는다.

## Considered Options

범위:

- **(채택) 행 복사·XLSX만 무료로 먼저**: 지금 엔진 그대로 할 수 있고, 유료 기능의 필요성은 실제 사용에서 확인한다.
- **자유 피벗까지(무료, Perspective)**: 무료지만 새 엔진(WASM)·탐색용 원 값 엔드포인트·화면이 필요하다. 요구가 확인되지 않았다.
- **셀 범위 복붙·채우기까지(AG Grid Enterprise 구매)**: 필요성이 확인되지 않은 비용이고, 망분리 라이선스 검증·테마·접근성 평가 전이다.

엔진과 메뉴의 경계:

- **(채택) 엔진을 메뉴에서 감춘다**: 메뉴는 플랫폼 소유 열 타입과 contracts `PageSort`만 쓰고, 엔진 import는 lint로 막는다. 비용은 래핑 한 층.
- **엔진 타입을 메뉴에 그대로 둔다**: 지금 당장은 비용이 없지만, 유료 엔진으로 바꾸는 날 모든 메뉴를 고쳐야 한다 — #160 이전 상태가 이것이었다.
- **지금 AG Grid Community로 교체**: 무료지만 §15 기능은 이미 있어 얻는 것이 적고, 원하는 기능은 결국 Enterprise다. 화면 모양이 바뀌어 디자인(M2) 컨펌도 필요하다.
- **무료 캔버스 그리드(Glide 등)**: 엑셀식 기능은 생기지만 캔버스 렌더링이라 06 §26 접근성·CSS 토큰·한글 입력 편집을 따로 검증해야 한다.

## Consequences

- 메뉴는 플랫폼 소유 열 타입(`PlatformColumn`, 정의는 `@ap/components`)과 contracts `PageSort`만 쓴다. 엔진 변환은 `@ap/components` 내부에만 있고 공개 진입점에 엔진 타입이 없다(테스트·lint로 고정, #160).
- 유료 전환이 필요해지면 [04 유료 전환 계획](../04_frontend_ui_ux.md#그리드차트데이터-도구-검토-2026-10-02)을 따르고, 읽기 기능은 메뉴 코드 변경 없이 `@ap/components` 안에서 바뀐다.
- 차트 엔진 판정(ECharts 유지, 두 번째 엔진 보류)과 공식 지표 집계 원칙은 04가 소유한다.
