# 페이지 머리는 한 줄을 유지하고 설명부터 폭을 양보한다

상태: **Decided (2026-10-16)**.
- 결정자: 사용자 — 2026-10-16, [#303](https://github.com/hjung3113/analytics-platform/issues/303) A안. 실제 앱 `?variant=` 시안을 캡처로 비교한 뒤 확정했다.

상세 패널이 열리면 페이지 머리가 좁아져, 1440에서 제목 폭이 0이 되고 1280에서 주 동작이 머리 가로 스크롤 밖으로 밀렸다. 머리 높이는 [06 §7](../06_platform_ui_contract.md#7-application-shell)과 [ADR-0011](0011-design-direction-feedbackops-shell.md)의 50px 한 줄이다. 양보 순서의 시각 원본은 [DESIGN.md 셸 시각 보완](../../DESIGN.md#shell-visual-rules)이다.

## 결정

- 폭은 뷰포트가 아니라 페이지 머리 컨테이너로 잰다. 렌더 중에는 재지 않는다.
- 50px 한 줄에서 양보 순서는 설명, Data Trust 요약, 잠정 배지, 제목 말줄임이다. 설명은 제목 옆 정보 아이콘 툴팁으로 남고, 요약의 이름은 tooltip·aria로 남는다. 제목은 최소 폭을 지켜 0이 되지 않으며 전체 이름은 기존 제목 툴팁과 `title`로 본다.
- 주 동작은 줄지 않는다. 보조 동작은 있을 때만 ⋯ 메뉴에 두며, 폭이 다시 넓어져도 줄로 돌아오지 않는다. 돌아오는 것은 설명·요약·배지다.
- 접힌 단계는 그 경계보다 넓은 폭에서 되돌려, 경계에 걸린 폭이 접고 펼치기를 반복하지 않게 한다.
- 줄바꿈은 쓰지 않는다. 모든 양보 뒤에도 들어가지 않을 때(예: 1024px + 펼친 사이드바 + 상세 패널)만 머리가 가로로 스크롤된다. 주 동작은 Tab 포커스나 스크롤로 닿으며, 시각 스크롤바는 감추지 않는다. 정상 폭(1280px 이상 + 상세 패널)에서는 스크롤이 생기지 않는다.

## Considered Options

- **(B) 정보 줄 분리**: 설명과 Data Trust를 머리 아래 두 번째 줄로 내린다. 시안 비교에서 기각했다. 정보 줄을 열면 50px 한 줄 계약을 깨고, 접으면 설명과 신뢰가 함께 사라진다.
- **(C) 정보 팝오버**: 설명과 Data Trust를 하나의 정보 팝오버에 넣는다. 시안 비교에서 기각했다. 폭이 남아도 둘 다 기본 줄에서 빠지고, 부족한 폭만 순서대로 양보하지 못한다.
- **(A, 채택) 한 줄에서 순서대로 양보**: 위 결정. 시안 캡처에서 1440·1280, 설비 요약이 열린 생산성 개요의 제목이 남고 주 동작이 화면 안에 있었다.

## 결과

- 시각 순서는 DESIGN 셸 시각 보완, 한 줄 계약은 06 §7이 소유한다. 소비자 props `primaryAction`·`secondaryActions`·`dataTrustSummary`는 바꾸지 않는다.
- 구현은 #303이다. 제목 포커스·툴팁(06 §26)은 이 결정의 범위가 아니다.
