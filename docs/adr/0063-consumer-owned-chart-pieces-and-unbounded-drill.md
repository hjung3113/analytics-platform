# 메뉴가 조립하는 차트 조각과 상한 없는 드릴 단계

상태: **Decided (2026-10-21)**.
- 결정자: 사용자 — #541, “왜 강제하고 있어”. 코디네이터의 확정 작업 범위: SDK 조각만 제공하고 메뉴별 의미는 메뉴가 선언한다.
- 대체: [ADR-0025](0025-drilldown-level-page-keys-path-bar-layout.md)의 깊이 4 제한. 단계별 page key·Context 초기화·경로 바·본문 교체 계약은 유지한다.

## 결정

메뉴 manifest가 필요한 수만큼 `drill.levels`를 선언한다. Registry는 비어 있지 않음과 키 계약을 검사하며 임의 깊이 상한을 두지 않는다. 단계·행·목적지의 의미를 공통 차트에 넣지 않는다.

공개 이름은 `AnalysisChartFrame`의 `pointActivation`, `pointActions`, `orientation`, `visibleSeriesIds`, `onVisibleSeriesChange`와 `ChartPoint`·`ChartPointAction`이다. 동작·기본값·우선순위의 원본은 [06 §16](../06_platform_ui_contract.md#16-analysis-chart-contract), 드릴 URL은 §6.4, 경로 바는 §12.7이다. 프레임 콜백은 내비게이션이 아니며 메뉴가 자신의 `useDrill` 등으로 연결한다.

## Considered Options

- **고정 깊이와 공통 도메인 계층**: 단순한 소비자 모양을 강제하지만 메뉴가 선언한 분석 구조를 SDK가 제한할 근거가 없다.
- **(채택) 상한 없는 선언 + 작은 조각**: 행 라벨·단계·액션은 메뉴가 소유하고 SDK는 가로 범주 막대·활성화·동작 메뉴·표시 제어를 제공한다.
- **raw ECharts 옵션 또는 그룹 축 계약**: 이 요구에는 불필요한 렌더러 결합·계층 해석을 추가한다. 범주 문자열 그대로인 행을 채택한다.
- **포인터 전용 활성화**: 키보드·터치의 동등한 실행 경로가 없다. 선택기와 눈에 보이는 실행·동작 버튼을 함께 제공한다.

가로 모드 Brush는 끄는 대신 세로 범주축의 범위를 선택한다. 지점 더블클릭 모드에서는 클릭이 선택만 하고 더블클릭만 활성화하며, Brush 모드가 지점 동작보다 우선한다. 이 세부 구현 선택은 #541에서 위임한 범위다.

## 결과

기존 소비자의 기본 차트 동작은 유지한다. 메뉴 화면·그룹/계층 축·TopN/Lane(#576)·분할 작업공간(#575)·workbook export(#541 C)는 이 구현 범위에 포함하지 않는다. #580 S4의 외부 시리즈 표시 제어만 이 조각에 포함한다.
