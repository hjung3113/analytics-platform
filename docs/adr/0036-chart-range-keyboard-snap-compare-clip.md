# 차트 구간은 키보드로 고르고 막대 경계에 맞추며 비교 중에는 현재 기간만 선택한다

상태: **Decided (2026-10-16)**.
- 결정자: 사용자 — 2026-10-15에 막대 경계 맞춤, KPI 이름에 기준, 비교 중 현재 기간 제한(추천안)을 골랐고, 2026-10-16에 키보드 구간 선택 A안(시작·끝과 프리셋)을 캡처로 확인했다.

차트 구간 선택·요약·주석·전역 기간 적용이 끌기로만 끝나 키보드로 같은 흐름을 끝낼 수 없었다(06 §26). 비교를 켠 채 구간을 끌면 이전 기간까지 골라져, 확인 뒤 전역 기간이 원래 조회 밖으로 옮겨갔다(#320). 느린 실행 KPI 이름은 기준을 말하지 않았다. 규칙의 원본은 [06 §16](../contract/chart.md#16-analysis-chart-contract)이다.

## 결정

- 키보드 경로는 선택 요약의 시작·끝 선택과 [선택], 그리고 구간 선택 옆의 `1시간`·`4시간`·`전체`다. [선택]과 프리셋은 차트 로컬 선택을 만들고, 전역 기간은 기존 "분석 구간 적용…" 확인으로만 바뀐다. 끌기는 보조 경로로 남는다.
- 시간축에서 고른 구간은 현재 기간 시리즈의 막대 시작과 조회 상한으로 바깥쪽에 맞춘다. 끌기와 키보드가 같은 함수를 쓴다. 범주축은 가장 가까운 범주다.
- 비교가 켜져 있으면 맞춘 다음 현재 조회 기간 안으로 자른다. 잘렸으면 선택 요약에 한 줄을 보이고, 전부 밖이면 선택하지 않고 이유를 보인다. 비교를 켤 때 이미 있는 선택과 열린 적용 확인도 같은 순서를 다시 탄다.
- 사이클타임 상세의 느린 실행 KPI 이름은 기준을 포함한다(`느린 실행 (P95 기준)`). 모집단 설명은 바꾸지 않는다.

## Considered Options

- **(B) 키보드 커서**: 구간 선택이 두 번째 조작 모드가 된다. 사용자가 캡처로 A안을 확인했으므로 기각한다.
- **(C) 두 손잡이 슬라이더**: 확인된 시작·끝 선택과 프리셋이 아니다. 기각한다.
- **(A, 채택) 시작·끝 선택과 프리셋**: 선택 요약에서 막대 경계를 고르고, 데이터 범위에 맞지 않는 프리셋은 숨긴다. 끌기·적용 확인·주석은 그대로다.

## 결과

- 계약은 [06 §16](../contract/chart.md#16-analysis-chart-contract)에 있다. 구현은 #307이다.
- 맞춤 다음 자르기, 경계에 조회 상한을 넣는 이유, 조회 끝이 없으면 키보드 경로를 그리지 않는 규칙은 그 절이 소유한다.
