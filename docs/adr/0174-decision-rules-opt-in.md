# 의사결정 규칙은 선택 적용 가능한 SDK 조각으로 제공한다

상태: **Decided (2026-11-19)**.
- 결정자: 소유자(리드를 통해) — 세 규칙을 opt-in SDK 조각으로 적용한다.

상세 표면의 되돌릴 수 있음, 판단 기록, 되돌릴 수 없음은 [Components §20](../contract/components.md#20-detail-surface-contract)의 공통 규칙이다. 각 소비자는 도메인 명령과 문구를 소유하고 SDK는 도메인을 모르는 입력·확인·실행 취소 부품을 제공한다. #2540의 적용 대상은 Finding «조치 불필요», Gate 결정, 권한 취소다.

## 결정

- `@ap/ui`는 선택 가능한 `DecisionRuleKind`와 실행 취소 토스트 액션, 한 줄 판단 사유 필드, 영향 확인 대화상자를 제공한다.
- 소비자는 해당 규칙을 명시적으로 선택한 동작에만 적용한다. 다른 기존 소비자의 기본 동작은 바꾸지 않는다.
- 되돌리기는 소비자의 기존 명령으로 수행하고, 확인 문구와 판단 기록의 도메인 문구는 소비자가 제공한다.

## Considered Options

- **화면마다 규칙을 직접 구현:** 공통 동작과 접근성 처리가 화면마다 달라질 수 있어 선택하지 않았다.
- **(채택) opt-in SDK 조각:** 공통 동작을 재사용하고 적용 여부는 소비자가 정한다.
- **모든 결정에 SDK 기본값 적용:** 기존 모든 소비자의 동작을 바꾸므로 선택하지 않았다.

## 결과

- 계약은 Components §20, 부품 사용법은 `packages/sdk/ui/docs/decision-rules.md`가 소유한다.
- #2540에서 세 대상 화면만 선택 적용한다. 새 소비자는 별도 선택 없이 기존 동작을 유지한다.
