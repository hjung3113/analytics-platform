# 로그 탐색은 서버 읽기 포트로 원본을 그때그때 읽고, 플랫폼에는 증거 참조만 저장한다

상태: **Decided (2026-11-07, 소유자 답 반영 — 토큰 호출·내보내기 허용, 증거 넘기기 이번 릴리스).** 결정자: 소유자(2026-11-07). 초안: 설계 레인, 근거 [#1344](https://github.com/hjung3113/analytics-platform/issues/1344), 설계 [`log-explorer`](../design/features/log-explorer/README.md).

## 배경

로그 탐색 워크벤치는 Round 없이도, Round 안에서도 같은 컴포넌트로 원본 레코드를 보여 준다. 원본·Parser 결과는 각 Source 소유자가 가지고 있고([ADR-0117](0117-validation-request-queue-claim-lease-heartbeat.md) 결정 7: 위치·해시와 짧은 발췌만 플랫폼), 소유자 ACL은 매 요청 확인해야 한다. 수천~수백만 줄 샘플을 브라우저가 통째로 다루면 안 된다.

## 결정

1. **원본 본문은 플랫폼 DB·로그·감사에 저장하지 않는다.** 탐색 요청 중 서버가 Source 어댑터에서 읽어 응답으로만 전달한다.
2. **서버가 `SourceReadPort`(어댑터 주입)로 읽는다.** 브라우저가 Source를 직접 부르지 않는다. 서버가 요청마다 `sourceOwner` 범위 ACL, 응답 행·본문 길이 상한, 시간 예산, 취소를 강제한다. 지원하지 않는 기능은 `unsupported` 상태로 돌려주고 가짜 결과를 만들지 않는다.
3. **저장하는 것은 `EvidenceRef`(`fileRef`, `line`, `fileSha256`, 메모)와 조사 상태뿐이다.** 증거를 다시 열면 그 순간 권한으로 다시 읽는다. 권한 철회 뒤 참조는 남고 본문은 열리지 않는다.
4. **원본 순서는 파일 순서→줄 번호이고 timestamp로 재정렬하지 않는다.** 시작/끝 쌍·상태 전이 같은 도메인 해석은 Source/Parser가 돌려준 기간 행을 그리기만 하고 프런트가 추론하지 않는다.
5. **토큰 호출과 내보내기를 허용한다**(소유자 2026-11-07; 초안 추천 «불허»와 다름). [ADR-0116](0116-platform-api-tokens-personal-and-service.md)의 scope ∩ 발급자 권한을 그대로 쓰고 추가로 둔다: 읽기와 내보내기를 별개 scope로 분리, 서비스 토큰은 `sourceOwner` grant 명시, 토큰·Actor별 일일 본문 예산, 내보내기는 요청마다 범위·행·바이트 상한과 동시 1건, 요청 때 스트리밍하며 저장·캐시 없음, 모든 읽기·내보내기·넘기기 감사(본문·필터 값 제외). 수치는 시작값이고 세부 규칙은 설계 문서 §4.1이 소유한다.
6. **증거 넘기기는 `EvidenceRef[]`(본문 없음)를 받는 쪽 서비스 인터페이스에 전달하는 것이다**(소유자 2026-11-07: 이번 릴리스). 받는 쪽(Round·지식 초안·결함)이 자기 계약대로 저장하고 탐색 모듈은 받는 쪽 DB에 쓰지 않는다. 전달은 공식 FAIL·기술 지식 확정이 아니다.
7. 운영 조립에 합성 어댑터를 넣지 않는다(CI가 확인). 합성 fixture 결과는 화면에 «합성»으로 표시한다.

## 대안과 버리는 이유

- **브라우저가 Source를 직접 호출(토큰 위임):** ACL·상한·감사가 클라이언트에 흩어지고 권한 철회가 즉시 반영되지 않는다. 기각.
- **로그를 플랫폼 DB에 수집·색인:** Raw Log 저장소는 비범위이고 원본 소유·보관 정책과 어긋난다. 기각.
- **토큰·내보내기 불허(초안 추천):** 소유자가 자동화와 반출 수요를 인정해 허용으로 정했다(2026-11-07). 유출 위험은 결정 5의 scope 분리·예산·감사로 줄인다.
- **발췌 캐시를 두고 오프라인 탐색:** 철회된 권한 뒤에도 본문이 남는 경로가 생긴다. 필요가 입증되면 [ADR-0117](0117-validation-request-queue-claim-lease-heartbeat.md) 발췌 정책(상한·보관·권한)에 맞춘 별도 결정으로 한다. 보류.
- **Round 화면과 독립 화면에 각각 전용 데이터 경로:** 같은 계약 요구(인수 기준 1)와 어긋나고 둘이 갈라진다. 기각.

## 결과

- 신규 모듈 `log-explorer`, `SourceReadPort` 계약(`@ap/contract-schemas v0`)과 계약 테스트 하니스, 합성 어댑터. 세부는 설계 문서가 소유하고 이 ADR은 결정만 둔다.
- 시험: 읽기 전용 토큰의 내보내기 거절, 일일 예산 초과 거절, 폐기·grant 철회 직후 호출 거절, 내보내기 범위 초과 거절·CSV 이스케이프, 권한 철회 뒤 증거 열기 거절, 상한 초과 `truncated`/`partial`, 요청 취소, 원본 부재, 운영 그래프에 합성 어댑터 없음, 본문이 감사·사용 이벤트에 없음.
- 실제 Source API가 확정되면 어댑터만 바꾸고 포트 계약을 바꿔야 하는 경우 이 ADR을 개정한다.
