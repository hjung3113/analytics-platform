# 접힌 분석 작업 영역은 조회 결과·페이지 조건·화면 배치를 조회 막대의 고정 둘째 줄에 둔다

- 상태: Decided (2026-11-14, 되돌릴 수 있음). 이슈 [#1941](https://github.com/hjung3113/analytics-platform/issues/1941).
- 결정자: 소유자 — 실제 앱 시안 B 승인(2026-11-14).
- 계약 원천: [layout §12.2 Analysis Workspace](../contract/layout.md#122-analysis-workspace). 관련: [ADR-0075](0075-page-head-one-line-fold-thin-outcome-strip.md), [ADR-0067](0067-dockview-layout-engine-board-v2.md).

## 맥락

사이클타임 상세의 조회 조건을 접어도 첫 데이터 위에 페이지 머리·조회 조건·조회 결과·파라미터 카드·배치 도구줄·패널 제목·차트 도구줄이 일곱 띠로 쌓였다. 1440×900에서 첫 차트는 y=355에서 시작했다. 작업 영역 패널 안의 StatCard도 테두리를 더해 경계가 겹쳤다.

## 검토한 안

| 안 | 시안의 첫 차트 y | 결과 |
| --- | --- | --- |
| 현재 | 355 | 편집기와 배치 도구줄이 별도 띠를 차지한다 |
| A | 324 | 상태·배치를 합치지만 파라미터 카드는 남는다 |
| B (채택) | 262 | 파라미터 카드를 페이지 조건 팝오버로 옮겨 세 띠를 합친다 |

## 결정

B를 기본 동작으로 채택한다. 적용 대상·둘째 줄의 순서·칩과 편집기·제외 상태는 [layout §12.2](../contract/layout.md#122-analysis-workspace)가 소유한다. 별도 variant·URL 키·저장값은 추가하지 않는다.

둘째 줄은 첫 행의 flex wrapping으로 만들지 않는다. wrapping은 넓은 창에서 첫 행으로 합쳐지고 좁은 창에서만 둘째 줄로 떨어져, 위치가 폭에 따라 바뀌었다. 첫 행의 기존 높이·패딩을 지키고 그 뒤에 독립된 행을 둔다. 소유자 승인 목표는 1440×900, 조회 조건 접힘에서 첫 차트 y ≤ 270이다(수정 시안 262). 초기 이슈의 y < 250 목표를 이 승인값으로 대체한다.

## 결과

- 결과 상태·페이지 조건 편집·배치 전환을 조회 막대에서 한 번에 접근한다. 기존 편집기와 배치 명령을 재사용한다.
- 펼친 조회 막대의 편집 흐름과 페이지 머리 선호값은 유지한다. 새 저장값이 없어 이 변경을 되돌리면 기존 배치로 돌아간다.
- 접힌 조회 막대 상태의 작업 영역 StatCard는 패널 경계를 쓰되 둥근 선택 링과 hover 표시는 유지한다. 독립 카드와 분석 보드 칸의 카드는 기존 경계를 유지한다.
- 위 좌표는 승인 시안 측정값이다. 구현의 데스크톱 캡처와 좌표 검증은 같은 조건에서 수행한다.
