# 표 열 너비는 머리 끝 끌기로만, 컬럼 목록은 보이기 체크박스와 줄 끝 핀

상태: **Decided (2026-10-08)**.
- 결정자: 사용자 — 표 컬럼 설정의 너비 슬라이더를 필터로 읽은 지적(#239)에서 "컬럼 드래그엔 드랍으로 넓이 조절하고 보이고안보일거만 체크박스로 안되나?", "마우스는 다쓰니까 일단 마우스도쓴다가정하고해"를 거쳐, 리서치 바탕의 실제 앱 위 `?variant=` 시안(브랜치 `hjung3113/proto-239-width-slider`) A/B/C/D 중 C를 골랐다("c").

`PlatformDataTable`의 "컬럼" 팝오버에는 열마다 보이기 체크박스, "고정" 체크박스, 너비 슬라이더(60–600px)가 있었다. 이름·값이 없는 슬라이더는 필터처럼 읽혔다. 리서치(shadcn·MUI·AG Grid·React Aria·TanStack·Mantine·Ant·PatternFly·Carbon)로는 너비는 헤더 오른쪽 끝 끌기가 표준이고 메뉴 안 너비 슬라이더는 쓰는 곳이 없었다. 보이기는 툴바 버튼 아래 체크박스 목록이 가장 흔하고, 고정은 헤더 메뉴나 목록 줄 끝 핀 아이콘으로 둔다. 표의 시각·조작 규칙은 [DESIGN.md](../../DESIGN.md)의 표 규칙이 소유한다([06 §27](../06_platform_ui_contract.md#27-performance-ux-baseline)은 열 너비·보이기·고정을 표 기본 기능으로만 둔다).

## 결정

- 열 너비는 헤더 오른쪽 끝을 끌어서만 바꾼다. 열 사이 1px 구분선이 늘 보이고(잡는 폭 8px, `col-resize` 커서), 마우스를 올리거나 끄는 동안 강조색이며, 더블클릭하면 그 열의 기본 너비로 돌아간다. 마우스 사용을 가정한다 — 키보드만으로 너비를 바꾸는 대체 수단은 지금 두지 않는다([05](../05_roadmap_and_open_questions.md)).
- "컬럼" 팝오버는 열마다 보이기 체크박스와 줄 끝 핀 토글(`aria-pressed`, "<열> 왼쪽 고정")을 둔다. 고정된 열은 위 "고정됨" 묶음, 나머지는 아래 묶음이다. 맨 아래 "기본값으로"가 보이기·너비·고정을 열 정의 기본값으로 되돌린다(정렬·페이지·선택은 그대로).

## Considered Options

- **(A) 현재 — 보이기·"고정" 체크박스 + 너비 슬라이더**: 슬라이더가 필터로 읽히고, 체크박스 두 칸이 조건 표처럼 보인다.
- **(B) 고정은 헤더 메뉴(⋮)**: MUI·AG Grid 방식이지만 열마다 메뉴 버튼이 머리 폭을 차지해 긴 열 이름이 꺾인다.
- **(C, 채택) 목록 줄 끝 핀 + 고정 묶음**: Ant ProTable·Mantine 방식. 보이기와 고정을 한 곳에서 정리하고 고정 상태가 위 묶음으로 바로 보이며, 표 머리는 그대로다.
- **(D) 체크박스만**: 가장 단순하지만 사용자 고정 기능이 없어진다.

## 결과

- `PlatformDataTable`의 컬럼 팝오버와 헤더 너비 손잡이가 바뀐다. 시안 코드는 본 코드에 넣지 않는다.
- 너비 조절의 키보드 대체 수단이 필요해지면(마우스 가정이 바뀌면) 이 결정을 다시 연다.
