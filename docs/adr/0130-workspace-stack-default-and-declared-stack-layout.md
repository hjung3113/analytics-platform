# ADR-0130 — 작업 영역은 아래로 쌓기로 시작하고, 메뉴가 쌓기용 배치를 선언한다

- 상태: Decided (2026-11-09, 결정자: 소유자, 컨펌 [1a 2a 3a](https://claude.ai/artifact/46q27mCH5W8ds3D6kmbGLr), 되돌릴 수 있음)
- 계약: [layout §12.8](../contract/layout.md), 이어받는 결정: [ADR-0077](0077-workspace-stack-mode-rows-keep-own-height.md)
- 이슈: [#701](https://github.com/hjung3113/analytics-platform/issues/701) (#686 3단계)

## 배경

ADR-0077로 `아래로 쌓기`가 들어왔지만 기본값은 `화면 맞춤`으로 남았고, 쌓기에서 쓰는 데 필요한 상호작용(포커스 보이기, 최대화 한계, 끌기)은 미뤘다. 소유자가 2026-10-23 "C를 기본 베이스로"라고 정했다. 세 가지가 남았다: 화면 맞춤을 어디서 고르는가, 사이클타임 `기본` 프리셋처럼 쌓기에서 줄이 하나뿐인 배치를 어떻게 하는가, 줄이 많아져 찾기 어려운 문제를 지금 풀 것인가.

## 결정

1. **`initialMode` 기본값은 `stack`이다.** 아무도 만지지 않은 작업 영역만 쌓기로 시작한다. 저장된 `fit`과 `mode`가 없는 옛 저장값은 화면 맞춤으로 읽고 저장값은 다시 쓰지 않는다. `initialMode="fit"`은 예전 시작을 지킨다. 좁은 폭에서 처음 보면 줄을 재거나 저장하지 않는다(한 화면과 보드 칸이 같은 키를 공유한다).
2. **화면 맞춤은 도구줄 끝 `⋯`에서 고른다 (1a).** `높이 방식` 라디오 묶음은 도구줄에서 빠지고 `⋯` 메뉴(`DropdownMenuRadioGroup`)로 간다. 호스트 메뉴(보드 칸)의 명령은 그대로다.
   - 대안 b: 도구줄에 세그먼트를 그대로 둔다 — 쌓기가 기본이 된 뒤에는 거의 쓰지 않는 선택이 한 줄을 차지한다.
3. **메뉴가 쌓기용 배치를 선언한다 (2a).** 선택 prop `stackPreset`(프리셋 id)이다. 만지지 않은 작업 영역은 쌓기로 시작하며 그 프리셋에서 시작한다. 모드를 바꿀 때는 지금 배치가 아직 한쪽 프리셋의 배치일 때만 다른 쪽을 적용한다(비교는 방향·자식 순서·그룹의 패널 집합이고 크기·활성 탭·탭 순서는 세지 않는다). 사용자가 바꾼 배치는 그대로 둔다. 상태를 더 저장하지 않으므로 새로 고침 뒤에도 같은 판정이 된다.
   - 대안 b: 메뉴가 기본 프리셋 자체를 `세로`로 바꾼다 — 화면 맞춤을 쓰는 사용자의 지금 배치가 바뀐다.
   - 선호 높이(`preferredHeight`)도 같이 들어온다: 패널이 내용이 넘치지 않는 본문 높이를 선언하고 새 줄이 그 높이로 시작한다. 줄이 하나이고 선언이 없으면 보이는 영역을 채운다(페이지 스크롤바 없음).
4. **도구줄 고정과 `패널로 이동` 목록은 하지 않는다 (3a, UX-13).** 줄 제거 때 스크롤 보정(UX-12)도 같다. 다시 여는 조건은 [백로그](../../.planning/backlog.md)에 있다: 쌓기 줄이 다섯 개 이상인 메뉴가 생기거나 찾기 불편 보고가 올 때(UX-13), 줄 제거 때 튐 보고(UX-12).
   - 대안 b: 지금 구현 — 줄이 둘~셋인 지금의 메뉴에서는 쓸 일이 없다.

## 결과

- 소비자: 사이클타임(`stackPreset="column"`, 패널 `preferredHeight`, 느린 실행 표는 패널을 채운다), HW Time 비교(줄 하나로 시작), 개요(이미 쌓기), 보드 칸의 작업 영역(칸 본문이 스크롤 컨테이너).
- SDK는 공개 prop `stackPreset`과 패널 필드 `preferredHeight`를 더한다(기본 동작에 영향 없음). 기본값 변화는 화면 맞춤을 기대한 테스트에 닿으므로 `initialMode="fit"`을 준다.
- 쌓기의 최대화는 보이는 영역 높이(도구줄 아래)를 쓰고 복원 때 스크롤 위치로 돌아온다. 프로그램이 준 포커스는 고정 머리 아래로 보이게 하고, 새 줄로 옮긴 뒤에는 그 줄로 스크롤한다. 줄 경계를 끌 때는 가장자리 자동 스크롤을, 탭을 끌 때는 아래 띠를 화면 아래에 붙인다. 세부는 layout §12.8.
