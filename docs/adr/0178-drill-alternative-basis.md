# 드릴 단계의 나누기 기준을 별도 page key로 저장한다

상태: **Decided (2026-11-26, #2739)**.
- 결정자: 사용자(«추천대로»).
- 부분 대체: [ADR-0025](0025-drilldown-level-page-keys-path-bar-layout.md)의 단계당 키 하나와 [ADR-0063](0063-consumer-owned-chart-pieces-and-unbounded-drill.md)의 단계 선언에 대안 기준을 추가한다.

## 결정

메뉴가 단계별 대안의 안정적인 `id`와 표시용 `label`을 선언한다. 표시용 문자열은 고정값이나 언어를 받는 함수다. 기본 기준은 기존 단계 선언에 포함되며 URL에 기준 키가 없는 상태로 표현한다. 대안을 고른 단계에만 `basisKey` 하나를 쓰면 링크와 메뉴 뷰가 같은 단계 값과 기준을 복원한다. 마지막 대안을 제거해도 기준 키를 등록해 두면 옛 주소를 한 단계 위로 복구할 수 있다.

기준의 의미와 사용 가능 여부는 메뉴가 소유한다. Kernel에는 적용 Context와 권한을 읽는 동기 판정 함수 `drill.isBasisAvailable`을 두고, 서버는 요청마다 권한과 Scope를 확인한다. 선언에 없거나 사용할 수 없는 기준은 해당 단계 앞까지 복원하고 단계 키만 담은 알림을 내보낸다. 세부 규칙은 [Kernel §5·§6.4·§21](../contract/kernel.md)에 있다.

## Considered Options

- **채택: 별도 단일 page key.** 기존 단계 값의 형식이 유지되고 기준만 바뀌어도 URL에서 구분된다.
- **기준과 값을 한 키에 저장.** 옛 값과 구분할 문법이 필요하고 기존 단계 값을 읽는 곳마다 해석이 달라진다.
- **화면 메모리에만 저장.** 링크·저장된 뷰·뒤로가기에서 기준을 복원할 수 없다.
