# ADR-0129 — 시안은 새 화면이거나 되돌리기 어려운 변경에만 만든다

- 상태: Decided (2026-11-09, 사용자 결정, 되돌릴 수 있음)
- 계약: [루트 AGENTS.md §UI](../../AGENTS.md#ui), [PROFILE §Review](../../.agents/conductor/PROFILE.md)

## 배경

보이는 모양이 바뀌는 모든 작업에 `?variant=` 시안과 소유자 컨펌을 요구했다. 시안 11건에 Sol 36회를 썼고, 그중 13회는 캡처였다.

## 결정과 이유

- **시안과 Artifact 컨펌은 시험 A(새 화면·라우트·Page Archetype·셸 영역·공개 시각 컴포넌트·토큰군·DESIGN.md 방향) 또는 B(모든 화면에 한 번에 영향, 메뉴가 맞춰야 하는 공개 SDK 변경, 저장되거나 링크되는 상태, 공간·메뉴의 이동·이름 변경, 사용자 기능 제거)일 때만 요구한다.** 이 PR 하나를 되돌려 사용자와 메뉴의 동작이 복원되면 B가 아니다.
- **나머지는 레인이 묻지 않고 처리한다.** 전후 캡처 1장을 붙이고 PR 본문 **Decisions**에 판단을 적는다. 소유자는 말로 되돌린다.
- **비용을 시안에 맞춘다.** `?variant=`의 impeccable critique는 없애고, 일관성 리뷰는 시안과 새 화면 PR에만 둔다. 캡처는 `research` 역할이 맡는다. 2–3안은 실제 배치 대안이 있을 때만 낸다.

## 채택하지 않은 것

- 모든 화면 변경에 시안을 유지: 되돌리기 쉬운 변경까지 소유자 대기와 Sol 비용을 치른다.
- 시안 전면 폐지: 공유 경로와 메뉴 구성은 소유자 몫이고, 새 방향은 글로 컨펌할 수 없다.

## 결과

재사용 부품 명시와 토큰 클래스 규칙(`prototype-consistency.md` 1–2)은 모든 화면 작업에 남는다. 시안 없이 나간 PR의 수는 다음 릴리스에서 PR 본문 **Decisions**로 확인한다.
