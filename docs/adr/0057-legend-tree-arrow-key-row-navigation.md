# LegendTree의 행 이동은 APG 트리 방향키로 하고 나머지 조작은 기본 키보드 경로로 제공한다

상태: **Decided (2026-10-20)**.
- 결정자: 사용자 2026-10-20 spec("ARIA treeview 표준: 방향키, 스페이스 체크") + 코디네이터.

범용 `LegendTree`는 계층별 보이기 체크와 별도의 단일 현재 항목 선택을 제공한다(#539). APG 트리의 한 Tab 진입점과 행 사이 방향키 이동은 [06 §26](../06_platform_ui_contract.md#26-accessibility-baseline)의 Tab 하한에 명시적인 예외가 필요하다. 세부 접근성 계약의 소유 문서는 06 §26이다.

## 결정

- 트리는 roving tabindex로 행 하나만 Tab 진입점으로 둔다. ↑/↓와 Home/End로 보이는 행을 이동하고, →/←로 펼침·접기 또는 자식·부모 이동을 한다. 행 사이 이동만 Tab 하한의 예외다.
- Space는 활성 행의 보이기를 바꾼다. Enter는 선택 모드에서 현재 항목을 선택하며, 그 밖에는 부모를 펼치거나 접는다(잎에서는 아무 동작 없음).
- 모든 모드에서 활성 행의 Tab 순서는 행 → 펼침·접기 버튼(부모만) → 정렬 버튼(조작 가능할 때만) → 트리 밖이다. Shift+Tab은 역순이다. 활성 행의 동작 버튼만 `tabIndex=0`이고 다른 행의 동작 버튼은 `-1`이다. 보이기 체크박스는 행의 Space로 조작하므로 Tab 정지점이 아니며, 읽기 전용 펼침 버튼은 비활성화되어 Tab에서 건너뛴다. 펼침·접기 버튼의 Enter/Space는 펼침을 바꾸고 버튼 포커스를 유지한다. 정렬 버튼의 Enter/Space는 없음 → 오름차순 → 내림차순 → 없음 순환이다. 읽기 전용 정렬 표시는 버튼이 아니며 행의 접근 가능한 설명으로 정렬 상태를 전달한다.
- Escape는 둘러싼 팝오버·대화상자에 맡긴다. 수정 키가 있는 키 입력을 가로채지 않으며, 별도의 단축키나 안내를 두지 않는다.
- 보이기는 복수 `aria-checked`, 현재 항목은 독립된 단일 `aria-selected`다. 현재 항목은 선택 표면·굵은 글자·2px 선으로 구별한다. `aria-multiselectable`은 설정하지 않는다.

## Considered Options

- **(A) 모든 행을 Tab 순서에 둔 disclosure list**: Tab 하한을 그대로 따르지만 사용자가 지정한 APG 트리 행 이동과 다르며 깊은 계층에서 Tab 정지점이 늘어난다.
- **(B, 채택) APG tree**: 방향키로 계층을 이동한다. 행 이동 예외를 명시하고 나머지 조작에는 Tab·Enter·Space 경로를 제공한다.

## 결과

- `@ap/components`의 `LegendTree`가 이 키보드 계약과 외부 포커스를 빼앗지 않는 복구를 소유한다.
- 브라우저·Windows 보조기술 검증은 코드·jsdom 테스트와 구별한다.
