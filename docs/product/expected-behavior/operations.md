# 운영 콘솔 기대 동작표

[기대 동작표](README.md)의 공간별 작성 예다. 공통 기대와 같은 내용은 적지 않는다. 표와 상세 패널의 기능별 기대는 [공통 부품](shared-components.md)을 따른다.

가는 길은 모두 Home에서 시작한다. Admin으로 홈 카드나 전환기의 `운영 콘솔`을 누른 뒤 사이드바에서 메뉴를 고른다.

| 플랫폼 기능 | 견본과 가는 길 | 맞는 모습 | 근거 | 확인 |
| --- | --- | --- | --- | --- |
| 공간 노출 | Developer·User의 Home, 전환기 | 운영 콘솔 카드와 전환기 항목이 없다 | [ADR-0110](../../adr/0110-platform-feature-roles-and-scope.md) | 화면 점검(실서버) |
| 메뉴별 권한 | Developer·User, 주소 입력 | 공간 진입 거부가 아니라 메뉴 권한 없음 화면이 나오고 주소가 유지된다 | [§9.1](../../contract/kernel.md) | 화면 점검(실서버) |
| 조회 전용 화면 | 권한/역할 관리 | 사용자별 권한, 그 권한이 여는 메뉴, Site별 room을 보이고 부여·회수 수단이 없다 | §9.1 | 화면 점검(실서버) |
| 감사 조회 | 변경 감사 | 변경 기록이 최신순으로 나오고 행위자, 작업, 대상 유형, 대상 ID를 보인다. 변경 필드와 사유 원문은 서버가 내지 않아([ADR-0069](../../adr/0069-platform-port-in-feedbackops-backend.md) 결정 6) 비어 있다. 상세 화면이 없는 대상은 `상세 화면 없음`으로 표시한다 | [체크리스트](../../integration/real-server-checklist.md) §2 `auditTrail` | 화면 점검(실서버) |
| 감사에서 대상으로 이동 | 변경 감사, 설비·지표 대상 행의 `상세` | 그 대상 상세의 변경 이력 탭으로 가고 복귀 버튼으로 돌아온다 | [§13](../../contract/components.md) AuditTimeline, §22 | 화면 점검(mock) |
| 쓰기의 감사 | 권한 요청 승인 뒤 변경 감사 | 작업 «변경» 행이 결정자(행위자)와 대상으로 남는다 | [05 정책](../../architecture/platform-api/05-permission-policy.md) | 화면 점검(실서버) |
| 활용률 계측 | 메뉴 활용률 | 다른 메뉴에 들어갔다 오면 그 메뉴의 방문 수가 늘고 방문 0 메뉴도 목록에 있다 | 체크리스트 §2 | 화면 점검(실서버) |
| 활용률 가림 | 메뉴 활용률, 행 선택 | «다음으로 간 화면»과 비율은 3명 미만인 칸을 드러내지 않는다 | 체크리스트 §2 `usageNextScreens` | 실서버 자동 |
| Registry 조회 | 메뉴 레지스트리 | 예정·숨김을 포함한 등록 메뉴 전체를 조회 전용으로 보인다 | [§5](../../contract/kernel.md)(예정 메뉴), 화면 설명 | 화면 점검(실서버) |
| 권한 요청 결정 | 권한 요청 검토 | 승인·거절·추가 정보 요청을 고를 수 있고 승인하면 권한이 생긴다. 본인 승인은 정책 허용과 근거·사유가 있어야 한다 | [안내서](../../user-guide/features/manual.md) §9 | 화면 점검(실서버) |
| 권한 회수 | 부여 목록 | 취소와 차단 해제에 사유가 필요하다. 변경 감사에 작업 «사용중지» 행이 행위자, 대상과 함께 남는다. 사유 원문은 감사 화면에 나오지 않는다 | 안내서 §10, 05 정책, ADR-0069 결정 6 | 화면 점검(실서버) |
| 서비스 토큰 | 서비스 토큰 | Admin만 발급한다. 값은 한 번만 보인다. 목록에 마지막 사용 시각이 있고 30일 미사용이면 경고한다. 발급·폐기가 변경 감사에 행위자, 시각, 권한 묶음과 함께 남는다 | [ADR-0116](../../adr/0116-platform-api-tokens-personal-and-service.md) | 화면 점검(실서버) |
| 시스템 연결 상태 | 시스템 | 업무 시스템별 추적 시스템과 연결 상태를 보이고, 끊긴 공간은 `연결 끊김`으로 표시한다 | ADR-0110 | 화면 점검(실서버) |
| 시스템별 VOC 등록 권한 | 시스템, 행 선택 | 상세 패널에서 열림·제한을 바꾸고 저장할 수 있다. 「플랫폼」 시스템은 제한으로 바꿀 수 없다. 변경이 감사에 남는다. 이 패널의 선택은 주소에 남지 않으며, §13과 다른 점은 기준 충돌로 적는다 | [ADR-0113](../../adr/0113-voc-creation-permission-per-managed-system.md) | 화면 점검(실서버) |
