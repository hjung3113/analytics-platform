# 운영 콘솔 기대 동작표

[기대 동작표](README.md)의 공간별 작성 예다. 공통 기대와 같은 내용은 적지 않는다. 표와 상세 패널의 기능별 기대는 [공통 부품](shared-components.md)을 따른다.

가는 길은 모두 Home에서 시작한다. Admin으로 홈 카드나 전환기의 `운영 콘솔`을 누른 뒤 사이드바에서 메뉴를 고른다.

| 플랫폼 기능 | 견본과 가는 길 | 맞는 모습 | 근거 | 확인 |
| --- | --- | --- | --- | --- |
| 공간 노출 | Developer·User의 Home, 전환기 | 운영 콘솔 카드와 전환기 항목이 없다 | [ADR-0110](../../adr/0110-platform-feature-roles-and-scope.md) | 화면 점검(실서버) |
| 메뉴별 권한 | Developer·User, 주소 입력 | 공간 진입 거부가 아니라 메뉴 권한 없음 화면이 나오고 주소가 유지된다 | [§9.1](../../contract/kernel.md) | 화면 점검(실서버) |
| 조회 전용 화면 | 권한/역할 관리 | 사용자별 권한, 그 권한이 여는 메뉴, Site별 room을 보이고 부여·회수 수단이 없다 | §9.1 | 화면 점검(실서버) |
| 감사 조회 | 변경 감사 | 변경 기록이 나오고 행의 링크가 그 대상의 변경 이력으로 간다 | [체크리스트](../../integration/real-server-checklist.md) §2 | 화면 점검(실서버) |
| 쓰기의 감사 | 권한 요청 승인 뒤 변경 감사 | 결정자와 대상이 감사에 남는다 | [05 정책](../../architecture/platform-api/05-permission-policy.md) | 화면 점검(실서버) |
| 활용률 계측 | 메뉴 활용률 | 메뉴에 들어가면 방문 수가 늘고, 방문 0 메뉴도 보이며, 3명 미만 집계는 가려진다. 열람은 Admin만 한다 | §9.1, 체크리스트 §2 | 실서버 자동 |
| Registry 조회 | 메뉴 레지스트리 | 예정·숨김을 포함한 등록 메뉴 전체를 조회 전용으로 보인다 | [§5](../../contract/kernel.md) | 화면 점검(실서버) |
| 권한 요청 결정 | 권한 요청 검토 | 승인·거절·추가 정보 요청을 고를 수 있고 승인하면 권한이 생긴다. 본인 승인은 정책 허용과 근거·사유가 있어야 한다 | [안내서](../../user-guide/features/manual.md) §9 | 화면 점검(실서버) |
| 권한 회수 | 부여 목록 | 취소와 차단 해제에 사유가 필요하고 감사에 `permission_revoked`로 남는다 | 안내서 §10, 05 정책 | 화면 점검(실서버) |
| 서비스 토큰 | 서비스 토큰 | Admin만 발급한다. 값은 한 번만 보인다. 목록에 마지막 사용 시각이 있고 30일 미사용이면 경고한다. 발급·폐기가 감사에 남는다 | [ADR-0116](../../adr/0116-platform-api-tokens-personal-and-service.md) | 화면 점검(실서버) |
| 시스템 연결 상태 | 시스템 | 업무 시스템별 추적 시스템과 연결 상태를 보이고, 끊긴 공간은 `연결 끊김`으로 표시한다 | ADR-0110 | 화면 점검(실서버) |
| 시스템별 VOC 등록 권한 | 시스템, 행 선택 | 상세 패널에서 열림·제한을 바꾸고 저장할 수 있다. 「플랫폼」 시스템은 제한으로 바꿀 수 없다. 변경이 감사에 남는다 | [ADR-0113](../../adr/0113-voc-creation-permission-per-managed-system.md) | 화면 점검(실서버) |
