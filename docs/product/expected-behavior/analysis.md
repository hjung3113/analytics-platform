# MARS·BRAVO·CLAS 기대 동작표

[기대 동작표](README.md)의 형식을 따른다. 공통 기대와 같은 내용은 적지 않는다. 표, 차트, 패널의 기능별 기대는 [공통 부품](shared-components.md)을 따르고 여기에 다시 적지 않는다.

세 공간은 실서버에 분석 권한과 Site 범위가 없어([체크리스트](../../integration/real-server-checklist.md) §8) mock 조립에서 확인한다. 값이 맞는지는 보지 않는다. 가는 길은 Home의 공간 카드에서 시작한다.

## 세 공간 공통

| 플랫폼 기능 | 견본과 가는 길 | 맞는 모습 | 근거 | 확인 |
| --- | --- | --- | --- | --- |
| 실서버 권한 | 실서버 Admin, 주소 입력 | 빈 화면이 아니라 메뉴 권한 없음 화면이 나오고 주소가 유지된다 | 체크리스트 §8, [§9.1](../../contract/kernel.md) | 화면 점검(실서버) |
| 역할별 노출 | mock, 개발 도구의 역할 전환 | 권한이 없는 역할에는 공간 카드와 전환기 항목이 나오지 않고 주소 입력은 권한 없음 화면이 된다 | §9.1, [§17](../../contract/kernel.md) | 화면 점검(mock) |
| Scope 선택기 | MARS 메뉴의 사이드바 머리 | 선택기는 한 곳에만 있고 바꾸면 다시 조회하며, 이전 Site의 값이 새 Site 결과처럼 남지 않는다 | [§11](../../contract/kernel.md), §6 | 화면 점검(mock) |
| 공간을 건넌 Context | MARS에서 기간을 바꾸고 전환기로 CLAS | 등록된 전역 Context를 보존하고 대상 화면이 지원하는 값만 적용한다 | §9.1 | 화면 점검(mock) |
| 공간 복귀 | MARS 안 메뉴를 열고 CLAS에 갔다가 레일·카드로 MARS | MARS의 마지막 화면으로 가고 전역 Context는 지금 값을 쓴다 | §9.1 | 화면 점검(mock) |
| 공유 링크 복원 | 조건을 적용하고 `현재 조건 공유`, 새 탭에 붙여넣기 | 같은 조건으로 열린다. 적용 전 초안과 `returnTo`는 들어가지 않는다 | §11 | 화면 점검(mock) |

## MARS

| 숨은 메뉴 | 설비 상세, 실행 상세 | 사이드바에 없고 부모 메뉴에서 들어간다 | [§5](../../contract/kernel.md) | 화면 점검(mock) |
| 예정 메뉴 | 기준정보관리, RCC, MCC, WPT, Configuration | 사이드바와 팔레트에 `예정`으로 나오고 눌러도 선언(권한, pageType, Context)만 보인다 | §5 | 화면 점검(mock) |
| 보드 칸의 분석 Context | 설비 마스터에서 분석 보드 열기 | 칸마다 자기 Context를 갖고 한 칸을 바꿔도 다른 칸이 바뀌지 않는다 | [§6.5](../../contract/kernel.md) | 화면 점검(mock) |
| 차트에서 만드는 개선 아이템 | 분석 메뉴 머리 `⋯` | 현재 분석의 출처가 붙은 등록 창이 열린다. 권한이 없으면 나오지 않는다 | [ADR-0106](../../adr/0106-improvement-task-is-quest.md) 개정 3 | 화면 점검(mock) |
