# 공통 부품 기대 동작표

[기대 동작표](README.md)의 형식을 따른다. 메뉴는 견본이며 표시되는 값이 맞는지는 보지 않는다. 메뉴가 노출하지 않은 기능은 점검 대상이 아니다.

견본 메뉴가 MARS, BRAVO, CLAS이면 실서버에서 열리지 않으므로 mock 조립에서 확인한다.
