# Home과 전역 메뉴 기대 동작표

[기대 동작표](README.md)의 형식을 따른다. 공통 기대와 같은 내용은 적지 않는다. 표와 상세 패널의 기능별 기대는 [공통 부품](shared-components.md)을 따른다.

가는 길은 모두 Home에서 시작한다. 전역 메뉴는 전환기 팝오버의 `플랫폼 메뉴` 구역이나 전역 화면 사이드바에서 고른다.

## 셸과 내비게이션

| 플랫폼 기능 | 견본과 가는 길 | 맞는 모습 | 근거 | 확인 |
| --- | --- | --- | --- | --- |
| 홈 런처 | 세 역할의 Home | 카드가 분석, 업무 운영, 도구, 플랫폼 관리 순서로 묶이고 빈 묶음은 나오지 않는다. 그룹 제목은 눌러서 접히지 않는다 | [ADR-0102](../../adr/0102-home-launcher-app-groups.md) | 화면 점검(실서버) |
| 홈 구성 | Home | 시스템 카드, `내 할 일`, 즐겨찾기·최근 방문, 공지 순서이고 카드에 메뉴 수나 건강 상태 숫자가 없다 | [15 §3.1](../../design/multi-workspace-ui.md) | 화면 점검(실서버) |
| 최근 방문 | 메뉴 몇 개를 열고 Home | 최대 5개이고 Home 자신은 없다 | 15 §3.1 | 화면 점검(실서버) |
| 카드의 이어서 | 공간 안 메뉴를 연 뒤 Home | 그 카드에 `이어서: <메뉴>`가 나오고 카드를 누르면 그 화면으로 간다 | [§9.1](../../contract/kernel.md) | 화면 점검(실서버) |
| 전환기 | 레일 맨 위 전환기 | 들어갈 수 있는 공간 카드만 나오고 보조 문구가 `이어서: <메뉴>` 또는 `시작: <메뉴>`다. 머리에 `플랫폼 홈`이 있다 | §9.1 | 화면 점검(실서버) |
| 현재 공간 다시 고르기 | 전환기에서 지금 공간 카드 | 이동 없이 닫히고 포커스가 전환기 버튼으로 돌아온다 | §9.1 | 화면 점검(실서버) |
| 공간 안 이동 | 공간 안에서 레일 섹션 버튼 | 사이드바가 그 섹션의 메뉴로 바뀌고 Home을 거치지 않는다 | §9.1, [ADR-0042](../../adr/0042-system-switcher-and-system-owned-rail.md) | 화면 점검(실서버) |
| 전역 화면의 셸 | 전역 메뉴를 연 화면 | 업무 시스템 사이드바가 붙지 않고 레일의 공간 표식이 꺼지며, 전역 화면 사이드바를 쓴다 | §9.1, [ADR-0070](../../adr/0070-global-features-platform-menu-and-voc-drawer.md) | 화면 점검(실서버) |
| 레일 로고 | 레일 로고 | 링크가 아니다 | §9.1 | 화면 점검(실서버) |
| 명령 팔레트 이동 | 공간 안에서 팔레트 열기 | 들어갈 수 있는 공간의 메뉴와 플랫폼 메뉴를 찾아 고르면 이동한다. 결과는 공간별로 묶이고 플랫폼은 별도 묶음이다 | [§10](../../contract/kernel.md), §9.1 | 화면 점검(실서버) |
| 팔레트 경로 표시 | 같은 결과 목록 | 보조줄이 `<시스템> › <섹션> › <메뉴>`이고 전역 메뉴는 `플랫폼 › <그룹> › <메뉴>`다 | §9.1 | 화면 점검(실서버) |
| 로그인 전 진입 | 로그아웃 상태, 주소 입력 | 로그인 화면으로 가고 로그인 뒤 원래 주소로 돌아온다 | [체크리스트](../../integration/real-server-checklist.md) §8 | 실서버 자동 |
| 서버 연결 실패 | 백엔드를 끈 앱 | 빈 화면이 아니라 연결 실패 화면이 나온다 | 체크리스트 §8 | 실서버 자동 |
| 링크 복사 | 전역 Context 바가 있는 MARS 메뉴, `링크 복사` | 본 버튼은 적용된 조건의 링크를 복사한다. 화살표에서 `메뉴 주소 복사`를 고를 수 있다. 실패하면 성공으로 표시하지 않는다 | [§11](../../contract/kernel.md), [안내서](../../user-guide/features/manual.md) §11 | 화면 점검(mock) |

## 전역 메뉴

| 플랫폼 기능 | 견본과 가는 길 | 맞는 모습 | 근거 | 확인 |
| --- | --- | --- | --- | --- |
| VOC 등록 | 레일 `VOC 등록` | 어느 화면에서든 오른쪽 등록 창이 열린다. 시스템, 제목, 상세 설명이 필수이고 제목은 200자까지다 | 안내서 §1 | 화면 점검(실서버) |
| 비슷한 VOC | 등록 창에서 시스템 선택 | 같은 시스템의 비슷한 VOC가 오른쪽에 나온다 | 안내서 §1 | 화면 점검(실서버) |
| VOC 목록 범위 | 소통 › VOC, `내가 등록한` | 내가 올린 VOC만 남고 주소에 남아 새로고침에서 복원된다 | 안내서 §2, [§6.4](../../contract/kernel.md) | 화면 점검(실서버) |
| 내 VOC와 남의 VOC | 소통 › VOC, 행 선택 | 내 VOC는 대화와 답글 입력이 있고, 남의 VOC는 공개된 답변만 보인다 | 안내서 §2 | 화면 점검(실서버) |
| 답글과 내부 메모 분리 | 내 VOC 상세 | 리포터 답장 입력창만 있고 내부 코멘트는 User에게 보이지 않는다 | 안내서 §2, §3 | 화면 점검(실서버) |
| 알림 종 | 레일 종 버튼 | 팝오버가 열리고 읽지 않은 수가 배지로 나온다. 읽음 처리하면 수가 줄어든다 | 안내서 §2, 15 §3.2 | 화면 점검(실서버) |
| 알림 목록 | 내 활동 › 알림 | `읽지 않음`과 `전체`를 고를 수 있고 읽음 처리와 보관이 된다. 안내서 §2의 Home `수신함` 탭(`/home?tab=inbox`)이 없으면 기준 충돌로 적는다 | 안내서 §2 | 화면 점검(실서버) |
| 내 Task 권한 | User의 Home, 팔레트 | `features:access`가 없으면 내 Task가 나오지 않고 주소 입력은 권한 없음 화면이 된다 | §9.1 | 화면 점검(실서버) |
| 내 Task 범위 | 내 활동 › 내 Task | 내게 배정된 Task만 나온다 | 안내서 §7 | 화면 점검(실서버) |
| 설문 응답과 복귀 | Home `내 할 일` 또는 소통 › 설문, 응답 뒤 제출 | 제출하면 출발 화면으로 돌아온다 | 15 §3.2 | 화면 점검(실서버) |

| 막힌 화면의 네 상태 | 권한이 모자란 업무 흐름 화면 | 정상, 승인된 요약, `권한 요청` 버튼, 차단 안내가 서로 다르다 | 안내서 §9 | 화면 점검(실서버) |
