# #1189 홈·시스템 전환기 시안 (2026-11-10 재검토)

실제 앱(mock, admin) 1440×900 @2x. 같은 준비 상태로 찍었다: MARS 방문 후 즐겨찾기, CLAS 방문, 홈. 전환기는 MARS `생산성 개요`에서 열었다.

| 파일 | 내용 |
| --- | --- |
| `home-{current,A,B,C}.png` | 홈 (즐겨찾기·최근·이어서 있음) |
| `home-empty-{current,A,B,C}.png` | 첫 방문 홈 |
| `switcher-{current,A,B,C}.png` | 전환기를 연 화면 |
| `switcher-collapsed-{current,C}.png` | 사이드바 접힘에서 전환기 (C 확인용) |
| `trigger-{current,A,B,C}.png` | 닫힌 트리거, 홈, 왼쪽 위 320×200 |

## 지난 시안(11-01)과 달라진 점

- 시스템이 바뀌어 다시 찍었다 (`개선 실행` → `업무 흐름`).
- 이슈의 요구가 "그룹 타일 유지"였는데 지난 3안은 모두 타일을 바꿨다. 타일을 유지하는 안 A를 새로 넣었다.

## 공통

- 설명 문장은 보이지 않는다. 짧은 부제만 남긴다.
- MARS와 CLAS의 부제가 둘 다 `생산성 분석`이어서 구별되게 바꿨다.
- 트리거: 파란 칩과 모서리 화살표를 없앴다. 레일 첫 섹션과 아이콘이 겹치지 않게 라틴 이름은 첫 글자(`M`), 홈은 중립 아이콘을 쓴다.
- 전환기 현재 표시는 사이드바와 같은 선택 배경과 굵은 글씨 하나. 제목 칸막이와 `시작:` 줄을 없앴고 플랫폼 메뉴는 시스템 아래로 옮겼다.
- 동작은 그대로다: 이어서 이동, 권한, 포커스, Esc, 내 할 일, 공지 닫기.

## A 타일 유지 (추천)

- 홈: ADR-0102 카드 그대로, 3열. 카드 한 줄(아이콘·이름·부제, 오른쪽 `이어서`). 그룹 제목은 작은 라벨.
- 전환기: 2열 유지, 한 줄 행. 약 512px로 지금(520px)과 비슷하고 높이는 더 낮다.
- 계약: `multi-workspace-ui.md` §3.1·§3.2 문구만 고친다. 위치 변경 없음.

## B 조용한 목록

- 홈: 카드 없이 행과 작은 라벨. 그룹을 열로 묶었다. 아래쪽 즐겨찾기·최근·공지도 같은 목록.
- 전환기: 1열 목록, 약 320px.
- 계약: A와 같고, ADR-0102 타일을 대체하므로 개정이 필요하다.

## C 이름 보이는 트리거

- 사이드바 머리가 전환기(`MARS ⇅`). 레일 맨 위는 홈 링크. 홈은 그룹 4열 한 줄.
- 계약 변경 필요: §3.2 "머리를 또 다른 전환기로 만들지 않는다", ADR-0042. 레일 홈 링크와 사이드바 `홈`이 겹친다.
