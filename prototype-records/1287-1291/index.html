세 화면(VOC 처리함 · Task 보드 · 분류) 모두 관리자 계정, 실서버 데이터입니다. 응답 설문 화면은 이 틀을 쓰지 않아 ②의 사용자 캡처에 지금 모습만 넣었습니다. 한 주소 값이 ①②③을 함께 바꾸므로, ③의 C 캡처 사이드바에는 ①의 C(영어 이름)가 함께 보입니다. 보드의 Backlog·Todo 같은 상태 이름은 용어 정리(D)에서 한국어로 바꿉니다.

C를 추천하는 이유
  • 틀만 고치면(A) 떠 보이는 문제는 풀리지만, 「다 선택된 것 같은 행」과 칩 6개는 남습니다. C가 사용자가 말한 「작업하는 부분이 이상함」을 한 번에 다룹니다.
  • 카드(B)는 기능 화면 안에 이미 테두리가 있어 상자 속 상자가 한 겹 더 생깁니다.
  • 틀 변경은 SDK 선택 옵션 하나(기존 화면 기본값은 그대로)라 다른 메뉴로 번지지 않습니다.
