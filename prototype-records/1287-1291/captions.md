# 시안 ①②③ 설명 (#1287–#1291)

실행: 실제 앱(`vite --mode real`) + 이 브랜치의 코어 서버(버리는 DB `platform_proto1287`, `SEED_MODE=personas` + preview 픽스처), 주소에 `?variant=A|B|C`(없거나 `now`면 지금 main). 캡처 1440×900, ego-browser.
②의 직속 VOC·공지 화면은 아직 서버 경로가 없어 화면 안 합성 데이터로 그렸다(실제 앱 틀·사이드바·권한 판정은 실서버). ①③은 실서버 데이터 그대로.

## ① 역할별 메뉴 배치

| 안 | 직속 그룹 | 업무 흐름 묶음 | 화면 이름 |
| --- | --- | --- | --- |
| 지금 | 내 활동(알림·내 VOC·내 Task·응답 설문·권한 요청), 공지(화면 없음) | 운영 콘솔 하나에 8개 섹션 | 수신함·Triage·Clusters·Evidence·Task Requests·Tasks·Milestones·Survey 관리·Managed System |
| A(추천) | 소통: 공지·FAQ(예정)·VOC·설문 / 내 활동: 내 Task·권한 요청 | 대시보드·VOC 처리·Finding·Task·설문 운영·연동·설정 (대상별) | VOC 처리함·분류·반복 VOC·근거·Task 요청·Task 보드·마일스톤·설문 관리·시스템·분석 영역·흐름 정책 |
| B | 참여: (A와 같은 4개) | 대시보드·접수·판단·실행·확인·설정 (단계별) | A와 같음 + 연결 추적·효과 확인 설문 |
| C | 소통: (A와 같음) | A와 같은 대상별 | 지금 영어 이름 그대로 |

운영 콘솔은 세 안 모두 플랫폼 관리·권한·시스템 세 묶음. 알림은 레일 종 하나(사이드바에서 뺌).
구현 규모: C1(공간·그룹·경로) + C2(홈·런처·E2E·문서) + D(용어). B는 그룹 이름만 다르고 크기는 같다.

## ② 직속 VOC·공지

| 안 | VOC 목록 | VOC 상세 | 공지 |
| --- | --- | --- | --- |
| A(추천) | 표: `전체 / 내가 등록한` + 시스템 선택, 시스템 배지(플랫폼 강조) | 본문·대화 + 오른쪽 정보 열, 처리 권한자에게 「업무 흐름에서 처리」 줄 | 목록, 고정 공지 위, 지난 공지는 토글로 |
| B | 목록 + 읽기 창(한 화면) | 진행 단계 줄 + 한 열 | 목록 + 읽기 창, 지난 공지는 「종료됨」 묶음 |
| C | 카드 피드(최근 답변 미리보기) | A와 같음 | 월별 카드, 지난 공지 숨김 |

구현 규모: K(목록·상세, G 서버 경로 뒤), L(공지). A는 기존 표·상세 부품 재사용이 가장 많다.
