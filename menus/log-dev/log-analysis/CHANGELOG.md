# Changelog

## 0.2.0

- #1474: 근거 위치 바구니의 「넘기기 › Round」를 확인 대화상자(승인된 #1473 A안)로 연결. 조사 자신의 Round로 참조만 전달하고 결과 개수를 알린다. 지식 초안 넘기기는 준비 중으로 둔다.

## 0.1.1

- #1473: 접힌 헤더에서도 도구 행·바구니 수 표시, 조사 만들기와 빈 상태 안내 정정, 타입 줄바꿈·서랍 제목·넘기기 메뉴·해시 라벨 수정.

## 0.1.0

- #1473: 승인된 A안의 로그 탐색·저장 조사·원본/시퀀스·근거 위치 서랍. 넘기기는 #1474 준비 중, REST 내보내기 연결은 미구현(어댑터 포트 없음). SDK `fill`을 사용한다.
