# Changelog

## 0.3.2 — 2026-11-14

- 화면 문구를 긍정형 개조식으로 정리하고 줄표·가능 표현을 줄임 (#1996).

## 0.3.1

- #1817: Round 원문 창 요청에 Round ID 전달. 서버가 등록 manifest의 파일 순서·SHA-256을 확인한 뒤 원문 반환.

## 0.3.0

- #1475: Round 상세 «원본/시퀀스» 탭 본문 `./view`(`RoundSourceView`, 읽기 전용·`source*` 주소 키). 조사 본문이 페이지 틀(`frame`)·주소 키 이름·읽기 전용(`embedded`)을 받는다. 앱 `main.tsx`만 이 경로를 import한다.
- #1474: 승인된 A안의 「지식 초안」 한 대화상자·두 탭. 소유 대상·관찰 사실로 새 초안을 만들거나 내 초안에 근거 위치를 덧붙이며, 원본 확인·제외·20개 한도·버전 충돌·작성 중 닫기 확인을 제공한다.
- #1474 수정: 탭 전환 후 소유 대상 표시 유지, 덧붙이기 추정치 차단 해제, 필드 오류 안내·필수 입력·초점 복구, 전달 개수 문구와 확정된 안내 간격 복원, 순번 줄바꿈 방지.

## 0.2.0

- #1474: 근거 위치 바구니의 「넘기기 › Round」를 확인 대화상자(승인된 #1473 A안)로 연결. 조사 자신의 Round로 참조만 전달하고 결과 개수를 알린다. 지식 초안 넘기기는 준비 중으로 둔다.

## 0.1.1

## 0.1.0

- #1473: 승인된 A안의 로그 탐색·저장 조사·원본/시퀀스·근거 위치 서랍. 넘기기는 #1474 준비 중, REST 내보내기 연결은 미구현(어댑터 포트 없음). SDK `fill`을 사용한다.
