# @ap/menu-log-models 변경 기록

내부 버전이며 발행하지 않는다. SDK 범위는 package.json의 ap.sdk를 따른다.

## 0.6.0 — 2026-11-12

- Round 수정 A: 규칙 결과 우선·설정/이력 분리, Gate 상세 슬롯과 사유 초안 보존, 규칙/결함 UUID 선택 복원 및 완료 시도와 최신 실행 분리(#1809). 결함·토론 공급은 #1808, 진단 리포트·첨부는 #1815에서 구현.

## 0.5.2 — 2026-11-11

- Round 규칙 결과의 의견 열·등급 필터, 연결되지 않은 의견 목록과 읽기 이력 드로어 및 합성 조회 fixture 추가(#1778).

## 0.5.1 — 2026-11-11

- Gate 결정 가능 여부 지표기가 지어낸 Trust(`provisional: false`로 «확정»처럼 보임)를 지우고 `DataTrustIndicator`의 `showWithoutTrust`로 평가 항목만 보인다(#1769).

## 0.5.0 — 2026-11-11

- `MetadataTable`이 가짜 `loadPage`와 `filterKey` 버전 대신 표의 `rows` 입력을 쓴다: 갱신해도 1페이지로 돌아가지 않고 선택이 남는다(#1672).

## 0.4.0 — 2026-11-08

- #1475: Round 상세 «원본/시퀀스» 탭(앱이 `./round-source-slot`으로 본문을 꽂을 때만 보임)과 규칙 결과의 「원본에서 보기」. 주소 키 `view`·`sourceTab`·`sourceFocus`·`sourceDrawer` 추가.

## 0.3.0 — 2026-11-08

- 시도 이력에 «규칙 세트» 열(RuleSet 링크·상태 문구)과 `LifecyclePage`의 `RuleSetLink`(#1496).

## 0.2.2 — 2026-11-08

- 계층 링크의 현재 모델·SW 표식과 Round 이동 시 경로 보존. 검증 요청 등록의 모델 검색을 목록 필터에서 분리하고 «미분류»·SW 합성 버전명 통일.

## 0.2.1 — 2026-11-08

- 모델 사이드바의 설비사·공정·모델·SW 계층 조회 연결. 개발 건 주소의 현재 노드 복원은 SDK 확장 결정 대기.

## 0.2.0 — 2026-11-08

- 확인된 A2 모델 표·개발 건/Round·검증 요청 화면과 Kernel menu-dispatch 연결.

## 0.1.0 — 2026-10-27

- 초기 기록: 화면 없이 계획 메뉴 manifest만 선언.
