- 개발 건 수정·단계 이동·Round 열기·요청 취소 양식은 제출할 때 빈 필수 칸과 잘못된 SHA-256에 칸별 오류를 표시하고 첫 오류 칸으로 포커스를 옮기며, 필수 표식을 «· 필수»로 맞춥니다. Gate 결정은 예외 입력이 빠져도 기록 버튼을 끄지 않고 칸별 오류를 보이며, 결정을 고르기 전에는 버튼이 꺼진 이유를 표시합니다.
- 요청 등록·댓글·검증 항목 등록도 필수 표식을 «· 필수»로 맞추고, 개발 건·Round를 고르지 않았거나 댓글·제목·설명이 비었거나 글자 수 상한을 넘으면 버튼을 끄는 대신 제출할 때 칸별 오류를 보이고 첫 오류 칸으로 포커스를 옮깁니다. 요청 등록 안의 «다음»·«이전»·«다시 시도»나 모델 검색의 Enter로는 요청이 등록되거나 제출되지 않습니다.
