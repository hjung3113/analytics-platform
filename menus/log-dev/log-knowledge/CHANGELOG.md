# @ap/menu-log-knowledge 변경 기록

내부 버전이며 발행하지 않는다. SDK 범위는 package.json의 ap.sdk를 따른다.

## 0.12.8 — 2026-11-15

- 카탈로그 상위 항목과 Item 소유 대상 선택에서 SDK Combobox의 선택값 라벨·목록 내 추가 조회 사용 (#2028).

## 0.12.7 — 2026-11-14

- 메뉴 소유 쓰기 표본과 생성기 등록으로 전환 (#2010).

## 0.12.6 — 2026-11-14

- 판단 변경의 「사유」 필드를 SDK `FormField`로 옮겨 도움말(「N자 이하」)이 오류 중에도 보이고 필수 표시가 입력에 닿는다. 사유·새 상태 오류에는 알림 역할이 없고, 저장이 막히면 첫 잘못된 입력으로 포커스가 옮겨진다 (#1890).

## 0.12.5 — 2026-11-14

- 화면 문구를 긍정형 개조식으로 정리하고 줄표·가능 표현을 줄임 (#1996).

## 0.12.4 — 2026-11-14

- #2108 기술 Item 수정·파생 서랍이 같은 사용자의 세션 갱신 재마운트 뒤 저장하지 않은 입력과 기준 버전(`baseVersion`)을 복원하고, 복원된 수정본이 서버 최신 버전과 다르면 덮어쓰지 않고 충돌 안내·«최신 불러오기» 확인을 거친다. 상세·최신 리비전 재조회가 끝나기 전에 이탈하거나 자리표시자에서 닫으면 임시 입력을 비운다.

## 0.12.3 — 2026-11-14

- #2109 판단 변경 충돌에서 최신 상태를 불러오는 동안 제출을 잠그고, 실패하거나 같은 버전이면 다시 불러오도록 안내한다. 새 버전 도착 후에도 사유와 닫기 확인을 유지하고 새 상태를 다시 고르게 한다.

## 0.12.2 — 2026-11-14

- #2073 명세 초안 충돌 복구: «최신 발행본 확인»이 최신 발행본(또는 열린 초안)을 읽기 전용으로 보이고, «바꾸기»/«내 입력 유지» 중 하나를 고르기 전에는 아무것도 쓰지 않는다. 고른 뒤에만 새 초안을 만들거나 열린 초안(Revision·version)을 이어받고, 발행 확인에 «기준 발행본 r{N}»을 보인다.

## 0.12.1 — 2026-11-13

- 모델 프로필 Top View 절의 `Studio에서 열기`: 손 가드(`registry.menus.some`)를 걷고 `resolveLink`의 `kind`로 가른다. `log-knowledge-model`이 `linkTargets.optional: ['eqv-studio']`를 선언한다(06 §22, ADR-0158, #1903). 화면은 그대로다.

## 0.12.0 — 2026-11-11

- #1656 모델 프로필 Top View 절: 모델에 연결된 게시 Layout Revision을 읽기 전용으로 보인다(`적용: <SW 버전 또는 모델 기본> · Layout · Revision`, 미연결, Revision 읽기 실패 표시). 모델 SW 버전이 있으면 `기준 SW` 선택으로 다시 읽고, 메뉴 `eqv-studio`가 등록돼 있고 권한이 있으면 `Studio에서 열기`를 보인다. 카탈로그 관리 권한자는 같은 절에서 연결(게시 Revision과 시작 SW 선택, 같은 시작 SW 행은 교체)과 해제를 한다. 그림은 앱이 `./model-topview-slot`으로 꽂는다(ADR-0128). mock에 합성 Layout 하나와 읽기 2개·쓰기 2개를 둔다.

## 0.8.0 — 2026-11-06

- 모델 명세(#1196 d, 로직 보정 2차): 텍스트 저장 뒤 다음 저장이 처음 읽은 초안으로 되돌리던 문제, Event 표가 갱신 응답 도착 전에 다시 읽던 문제, Event 클릭이 편집 중 초안을 확인 없이 버리던 문제를 고쳤다. 서버의 행·칸 단위 오류(TSV 줄/열, 대체 변경점 경로)를 해당 입력 칸에 위치와 사유로 보여 주고, 저장 중에는 `aria-busy`와 «저장 중…» 표시를 둔다. mock은 잘못된 종류에 필드 오류를, TSV에 2,000행 상한과 20건 오류 요약을, 대상 이름에 서버와 같은 정규화·키를 쓴다.

- 모델 명세(#1196 d, A안 시각 보정): Event 표 영역의 가로 넘침을 내부로 제한하고, 변경점 전후 비교·원본 JSON 펼치기·대상별 JSON 예시를 추가했다. 모델 이름·코드·제조사와 발행 확인의 초안 Revision·원본 문서 버전을 표시하고, Event 상세에 필드·관계 빈 상태와 연결 변경점 근거를 보여 준다.

- 모델 프로파일의 명세 링크와 숨김 모델 명세 화면(#1196 d, 확정 A안): 접히는 Module 트리·Event 표/상세, SW 실효 명세 표시, 변경점·Revision 이력 탭, 초안 작성·저장·발행·반려와 변경점 추가·닫기/대체·재검토 확인. 서랍의 저장·확인 버튼은 SDK 선택 footer 슬롯에 둔다. 권한 안내·충돌 입력 보존·URL 상태·한영 문구와 결정적 mock 읽기 4종·쓰기 7종을 추가했다. 개념 매핑·Item 대상 연결은 후속 노드다.
