# @ap/menu-log-rules 변경 기록

내부 버전이며 발행하지 않는다. SDK 범위는 package.json의 ap.sdk를 따른다.

## 0.5.3 — 2026-11-14

- 화면 문구를 긍정형 개조식으로 정리하고 줄표·가능 표현을 줄임 (#1996).

## 0.5.2 — 2026-11-14

- 결과 검토 라벨 입력에 실행 항목 순번을 포함해 같은 Revision의 다른 결과와 구분한다(#2107).

## 0.5.1 — 2026-11-11

- Baseline 승인 가능 여부 지표기가 지어낸 Trust(`provisional: false`로 «확정»처럼 보임)를 지우고 `DataTrustIndicator`의 `showWithoutTrust`로 평가 항목만 보인다(#1769).

## 0.5.0 — 2026-11-11

- 테스트 데이터셋 목록 표가 가짜 `loadPage`와 `filterKey` 버전 대신 `rows`·`rowsLoading` 입력을 쓴다: 갱신해도 1페이지로 돌아가지 않고 선택이 남는다(#1672).

## 0.4.0 — 2026-11-08

- 테스트 데이터셋 목록·탭 상세·Baseline 승인·회귀 실행·비교와 결과 검토 라벨 추가, 회귀 비교의 실행 페이지·Suite 고정값 복원과 미산출 상태·키보드 근거 열람(#1481).

## 0.3.0 — 2026-11-08

- 커버리지 탭의 모델·SW 버전 선택기(서버 검색·페이징, 주소 UUID 키는 그대로, 라벨을 못 붙이는 id는 그대로 표시)와 `logRules.modelOptions|softwareOptions` 선언(#1496).

## 0.2.1 — 2026-11-08

- 커버리지 스냅샷 충돌 복구, URL 필터 검증·대상 원문 필터, 도착 포커스·탭 패널 연결, 표 요약·서랍 표현과 빈 결과·RuleSet 탐색 복구(#1495).

## 0.2.0 — 2026-11-08

- 검증 규칙·명세 커버리지 탭과 조회 전용 상세·Revision 이력 서랍 구현. 안정 ID·표 상태 URL 복원, 합성 fixture와 서버 선언 드리프트 검사 추가(#1495, ADR-0122).

## 0.1.0 — 2026-10-27

- 초기 기록: 화면 없이 계획 메뉴 manifest만 선언.
