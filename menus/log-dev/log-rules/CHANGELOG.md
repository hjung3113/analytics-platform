# @ap/menu-log-rules 변경 기록

내부 버전이며 발행하지 않는다. SDK 범위는 package.json의 ap.sdk를 따른다.

## 0.3.0 — 2026-11-08

- 커버리지 탭의 모델·SW 버전 선택기(서버 검색·페이징, 주소 UUID 키는 그대로, 라벨을 못 붙이는 id는 그대로 표시)와 `logRules.modelOptions|softwareOptions` 선언(#1496).

## 0.2.1 — 2026-11-08

- 커버리지 스냅샷 충돌 복구, URL 필터 검증·대상 원문 필터, 도착 포커스·탭 패널 연결, 표 요약·서랍 표현과 빈 결과·RuleSet 탐색 복구(#1495).

## 0.2.0 — 2026-11-08

- 검증 규칙·명세 커버리지 탭과 조회 전용 상세·Revision 이력 서랍 구현. 안정 ID·표 상태 URL 복원, 합성 fixture와 서버 선언 드리프트 검사 추가(#1495, ADR-0122).

## 0.1.0 — 2026-10-27

- 초기 기록: 화면 없이 계획 메뉴 manifest만 선언.
