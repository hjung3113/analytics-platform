# @ap/menu-clas 변경 기록

내부 버전이며 발행하지 않는다. SDK 범위는 package.json의 ap.sdk를 따른다.

## 0.2.5 — 2026-11-15

- 주소의 `eqp`(또는 응답이 보이는 설비)가 설비별 동작시간 차트에서 선택된 채로 보인다. 상위 10대 밖이면 선택 요약이 그렇게 말한다. 응답 순위 상한(30대) 밖 설비는 응답의 `equipmentRow`로 자기 행을 받는다 (#2187).

## 0.2.4 — 2026-11-15

- eqp 대상의 들어오는 연결과 머리 다른 화면 목록을 선언 (#1930).
- 다른 화면의 목록에서 열리면 `returnTo`를 받아 머리 ⋯에 출발 화면으로 돌아가는 버튼을 보인다 (#1930).

## 0.2.3 — 2026-11-14

- 벽시계 표시 함수 공통화 (#2010).

## 0.2.2 — 2026-11-14

- 가동 시간 KPI의 평균 칩을 amber에서 blue로(#1945, StatCard 칩은 blue·teal만).

## 0.2.1 — 2026-11-07

- CLAS 운영시간이 `subjectPageKeys`(설비 `eqp`)를 선언한다. 고른 설비가 「개선 아이템 남기기」 서랍의 대상 제안이 된다(#1430).

## 0.2.0 — 2026-11-05

- CLAS 운영시간에서 설비를 바꾸면 이전 순위·흐름이 새 결과가 올 때까지 남는다(#1365, [ADR-0114](../../../docs/adr/0114-opt-in-keep-previous-for-page-input-params.md)).

## 0.1.2 — 2026-11-01

- OperationTime에서 `density="compact"` 선언을 걷는다 — SDK 기본 밀도가 compact로 바뀌었다(#1217, 06 §12).

## 0.1.1 — 2026-10-31

- OperationTime은 분석 페이지로서 `density="compact"`를 선언한다(#1166, 06 §12.2).

## 0.1.0 — 2026-10-27

- 초기 기록: OperationTime.
