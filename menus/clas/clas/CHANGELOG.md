# @ap/menu-clas 변경 기록

내부 버전이며 발행하지 않는다. SDK 범위는 package.json의 ap.sdk를 따른다.

## 0.2.14 — 2026-11-24

- (#2876) 동작시간 패널의 날짜 구간 필터를 등록하고, 분석 선택에서 받아 조회에 적용합니다.

## 0.2.13 — 2026-11-24

- (#2735) HW Time에서 받은 날짜 구간을 조회 조건 칩에 표시하고, 적용 기간 안에 들어오는 날짜 구간으로 CLAS 조회를 좁힙니다. 날짜 구간을 적용할 수 없으면 요약 위에 안내합니다.

## 0.2.12 — 2026-11-23

- (#2792) 동작 흐름 Lane의 표로 보기 상태 칸에 동작 종류 이름(코드값 대신)을 보입니다.

## 0.2.11 — 2026-11-23

- (#2770) 조회 이력 연결에서 빈 현재 요약·문제 목록을 지움. 동작은 그대로다.

## 0.2.10 — 2026-11-22

- (#2691) 조회 이력 줄이 고른 설비를 보인다. 설비만 다른 두 이력이 같은 글로 보이지 않는다.

## 0.2.9 — 2026-11-19

- (#2541) 동작시간 요약의 최근 갱신에 공통 시각 표기를 적용했습니다.

## 0.2.8 — 2026-11-19

- 동작시간 평균을 분으로 표시하고 공동 최장 설비와 응답 갱신 시각을 명시 (#2532).

## 0.2.7 — 2026-11-18

- (#2503) 동작시간 조회에 공통 일괄 적용과 저장된 뷰 사용. 첫 진입에 기본 조회를 실행하며 기간 없는 조건·설비 링크 진입도 기존 조건을 유지한 채 기본 기간을 채워 조회하고, 선택 설비도 메뉴 뷰에 저장.

## 0.2.6 — 2026-11-15

- 빈 동작시간 순위 응답 처리 (#2056).

## 0.2.5 — 2026-11-15

- 주소의 `eqp`(또는 응답이 보이는 설비)가 설비별 동작시간 차트에서 선택된 채로 보인다. 상위 10대 밖이면 선택 요약이 그렇게 말한다. 응답 순위 상한(30대) 밖 설비는 응답의 `equipmentRow`로 자기 행을 받는다 (#2187).

## 0.2.4 — 2026-11-15

- eqp 대상의 들어오는 연결과 머리 다른 화면 목록을 선언 (#1930).
- 다른 화면의 목록에서 열리면 `returnTo`를 받아 머리 ⋯에 출발 화면으로 돌아가는 버튼을 보인다 (#1930).

## 0.2.3 — 2026-11-14

- 벽시계 표시 함수 공통화 (#2010).

## 0.2.2 — 2026-11-14

- 가동 시간 KPI의 평균 칩을 amber에서 blue로(#1945, StatCard 칩은 blue·teal만).

## 0.2.1 — 2026-11-07

- CLAS 운영시간이 `subjectPageKeys`(설비 `eqp`)를 선언한다. 고른 설비가 「개선 아이템 남기기」 서랍의 대상 제안이 된다(#1430).

## 0.2.0 — 2026-11-05

- CLAS 운영시간에서 설비를 바꾸면 이전 순위·흐름이 새 결과가 올 때까지 남는다(#1365, [ADR-0114](../../../docs/adr/0114-opt-in-keep-previous-for-page-input-params.md)).

## 0.1.2 — 2026-11-01

- OperationTime에서 `density="compact"` 선언을 걷는다 — SDK 기본 밀도가 compact로 바뀌었다(#1217, 06 §12).

## 0.1.1 — 2026-10-31

- OperationTime은 분석 페이지로서 `density="compact"`를 선언한다(#1166, 06 §12.2).
