# @ap/menu-configuration 변경 기록

내부 버전이며 발행하지 않는다. SDK 범위는 package.json의 ap.sdk를 따른다.

## 0.3.9 — 2026-11-26

- (#2997) 적용 기간을 붙잡은 HW Time 추세를 아래에 추가합니다. 원본 추세를 닫아도 비교본은 매트릭스에서 고른 항목을 따라가며, 저장된 뷰는 저장 당시의 추세 슬롯을 다시 엽니다. 비교본에서 고른 날짜는 비교 차트 안에만 표시합니다.

## 0.3.8 — 2026-11-23

- (#2792) 설정값 추세(문자열)의 표로 보기·CSV 상태 칸에 설비별 값과 미수집을 보입니다.

## 0.3.7 — 2026-11-19

- (#2541) 설비 구성 상세의 수집 시각에 공통 요약 표기를 적용했습니다.

## 0.3.6 — 2026-11-19

- (#2550) Configuration 응답에서 비교 열의 설비와 항목의 Motion 연결을 읽는다. HW Time 설비와 연결되지 않은 비교 열이 있으면 선택 옆에 열 이름을 표시한다.

## 0.3.5 — 2026-11-18

- (#2490) 설정값 추세 옆에 선택 항목의 HW Time 동작시간 추세를 연다. 조회에는 확인된 Scope가 필요하다. HW Time 추세를 닫으면 선택 셀이나 화면 본문으로 초점이 돌아간다.

## 0.3.4 — 2026-11-18

- (#2498) Configuration 설비 기준 비교, 저장된 뷰 복원과 200개 항목 표시 상한.

## 0.3.3 — 2026-11-18

- (#2525) 선택 상세 드로어를 열어도 행렬 행이 남음. 상세 조회는 드로어 탭 안에서 불러옴.

## 0.3.2 — 2026-11-18

- (#2503) 저장된 뷰는 Analysis 기본값으로 사용. 첫 진입 기본 조회와 뷰 복원은 그대로 제공.

## 0.3.1 — 2026-11-18

- 비교 행렬을 패널 안에서 스크롤하고, 숨긴 추세는 항목을 직접 열면 다시 표시.

## 0.3.0 — 2026-11-18

- 비교 행렬 아래에 기간별 합성 설정값 추세를 추가. 항목을 더블 클릭하거나 Enter로 열고 적용 기간과 설비를 함께 사용.

## 0.2.4 — 2026-11-18

- 첫 진입에서 화면을 불러오는 중에도 개인 기본 뷰를 먼저 판정하도록 저장 뷰 지원 범위를 메뉴에 선언.

## 0.2.3 — 2026-11-18

- 검색 갱신 중 이전 결과의 행 작업과 내보내기 제한, 초과 내보내기 응답 수정, 미사용 기준 설비 표시 및 요약 여백 정렬.

## 0.2.2 — 2026-11-18

- 요약·신뢰 상태·검색·필터·도구를 한 툴바로 통합하고 검색 중 포커스와 일시적 행렬 상태 초기화 유지.

## 0.2.1 — 2026-11-18

- 커널 초안·적용으로 비교 조건과 기간을 함께 반영하고 적용 조건을 라벨로 표시. 설비 전체 해제는 명시적 빈 값으로 유지하며 적용 사유 표시.
- 기본 Module/Category 그룹, 검색·윈도 전환 포커스 유지, 내보내기 거절 사유와 강조 여백 수정.
- 맨 주소로 처음 열면 커널의 `query.autoApplyDefault`가 기본 기간을 적용해 행렬을 조회. 개인 기본 뷰가 있으면 먼저 적용. 합성 최신 값은 기간 종료 시점 값으로 해석하며 추세·이력은 추가하지 않음.

## 0.2.0 — 2026-11-18
