# @ap/menu-analytics 변경 기록

내부 버전이며 발행하지 않는다. SDK 범위는 package.json의 ap.sdk를 따른다.

## 0.5.6 — 2026-11-14

- 접힌 분석 작업 영역 조회 막대에 요약 조회 실패 상태와 응답 시각을 전달(#1941).

## 0.5.5 — 2026-11-14

- 화면 문구를 긍정형 개조식으로 정리하고 줄표·가능 표현을 줄임 (#1996).

## 0.5.4 — 2026-11-14

- 생산성 개요·사이클타임 상세·실행 상세의 `room_name` 화면 라벨과 점유 구성 차트 제목(`공정별 점유 구성`)을 `공정`(`Process`)으로 통일(#1993).
- 정비 시간에 Job이 없는 설비도 점유 구성의 공정·StGroup과 관측 분모에 포함해 KPI·드릴 점유율을 맞췄다(#1999).
- mock Job 생성기에 시간대별 변동을 넣어 「Job 처리량 추세」가 평평하지 않게 했다(#1999). 교대 경계(06·14·22시) 하락, 일부 설비 정비 구간(02–04시), 완만한 시드 변동을 반영했으며 총합·Scope·PPID/Recipe 불변식은 그대로 유지된다.
- 생산성 개요의 다섯 조회(KPI 요약·추세·점유 구성·드릴·주의 목록)가 적용된 PPID·Recipe로 Job 모집단을 좁힌다(#2072). 설비 수·관측 bucket 수는 그대로다. `CYCLE_VERSION_NOTE`는 건수가 조건이 같을 때만 두 화면에서 같다고 말하도록 고쳤다(Lot은 사이클타임 상세에만 적용).

## 0.5.3 — 2026-11-14

- 생산성 개요·사이클타임 상세의 StatCard 칩을 blue·teal로 맞추고(purple→teal, amber→blue), 처리량 차트 계열 색을 카드 칩과 같은 blue로(#1945).

## 0.5.2 — 2026-11-14

- 생산성 개요·사이클타임 차트가 응답 `Trust`를 그대로 넘긴다. 꼬리말 표기는 SDK가 머리 Trust 표시와 같은 함수로 만든다(갱신 `MM-DD HH:mm`, 보는 사람의 시간대, 커버리지 없음 「미확인」). 메뉴의 `chartTrust`·`trustLine`·`coverageText`를 지웠다(#2009, #2044).

## 0.5.1 — 2026-11-09

- 사이클타임 작업 영역이 아래로 쌓기로 시작하고(`stackPreset="column"`), 패널이 `preferredHeight`를 선언하며, 느린 실행 표가 패널 높이를 채운다(#701, ADR-0130).

## 0.5.0 — 2026-11-08

- 차트 카탈로그에 순서 트랙 합성 견본(`kind=sequence`) 추가: 12개 줄·약 3,000항목, 취소 가능한 범위 조회, 파일 경계·시간 역전·열린 구간·이월, 키보드·구간 선택·항목 목록 검증. 축 단위 «순번»과 내용 폭의 상세 배지, SDK 표·툴팁·토글 문법 적용(#1471).

## 0.4.2 — 2026-11-07

- 생산성 개요가 `subjectPageKeys`(설비 `drillEquipment`, 공정 `drillRoom`)를 선언한다. 머리 ⋯의 「개선 아이템 남기기」가 드릴 대상을 지울 수 있는 대상 제안으로 채운다(#1430).

## 0.4.1 — 2026-11-05

- 생산성 개요(추세 제목·단위·집계 단위 설명, 구성 표 머리글·제목·CSV·방 들어가기)와 사이클타임(추세 설명·점 클릭)이 보존된 결과를 불러온 때의 KPI·축·집계 단위 기준으로 말한다. 사이클타임은 집계 단위를 바꾸는 중에 점 클릭을 막는다(이전 단위의 버킷을 새 단위로 읽지 않게).(#1365 수정 라운드)

## 0.4.0 — 2026-11-05

- 생산성 개요의 KPI 카드·그룹 기준 탭·집계 단위와 사이클타임의 집계 단위를 바꾸면 지난 차트·막대가 새 결과가 올 때까지 남고 «같은 조건으로 갱신 중» 표시만 뜬다(로딩 뼈대 없음, #1365, [ADR-0114](../../../docs/adr/0114-opt-in-keep-previous-for-page-input-params.md)). 기간·Scope·Context를 바꾸면 이전처럼 가려진다. 차트 카탈로그의 종류 선택은 다른 차트라 끈 채로 둔다.

## 0.3.4 — 2026-11-05

- 사이클타임 드릴다운: 집계·느린 실행 기준·정렬과 버킷·분포 구간을 표 필터와 같은 칩 줄에 모은다(#1218). 적용된 값만 보이고, 초안은 상단 적용을 기다린다. 버킷·분포 구간의 ×는 해당 조건만 바로 지우며, 접어도 적용된 조건 줄은 남는다.
- 사이클타임 드릴다운: 버킷·분포 구간 값을 한 가지 글자로 보인다(#1218). 칩·조건 요약·XLSX 조회 정보가 `src/bucket-format.ts`를 함께 쓴다 — 시간 버킷은 `2026-09-25 10:00 → 11:00`(날이 바뀌면 `2026-09-25 23:00 → 2026-09-26 00:00`), 일·주 버킷은 날짜만, 분포 구간은 축과 같은 `45-60 – 60-75`. 못 쓰는 값은 원문 그대로 보인다.

## 0.3.3 — 2026-11-01

- 페이지 4종(생산성 개요·사이클타임 드릴다운·실행 상세·차트 카탈로그)에서 `density="compact"` 선언을 걷는다 — SDK 기본 밀도가 compact로 바뀌었다(#1217, 06 §12).

## 0.3.2 — 2026-11-01

- 차트 카탈로그: 종류 탭의 `지원 N/8` 표기를 걷고(트리거 `aria-label`의 지원 수는 유지), 넘치는 탭은 `TabsList overflow="menu"`의 `더보기` 메뉴로 옮긴다(#1190).

## 0.3.1 — 2026-10-31

- 분석 페이지(차트 카탈로그·사이클타임·실행 상세)와 생산성 개요는 `density="compact"`를 선언한다(#1166, 06 §12.2).
- 실행 상세: 패널 사이 간격을 12px로 통일(이중 상단 여백 제거, QueryView 안 패널에 간격 추가)하고 구간 표를 일반 표와 같게 맞췄다(셀 좌우 16px, 머리글 한 줄 말줄임 + `title`)(#1166).

## 0.3.0 — 2026-10-27

- occurrence anchor는 파서 RecordSequence(불투명 숫자 문자열)이고 시작 시각은 별도 필드 `startedAt`이다. 실행 표의 시작 열 정렬은 `sort=startedAt:*`(옛 `sort=anchor:*`는 거절), ExecutionDetail은 시작 시각을 별도 칸으로 보인다(#1007, ADR-0094).

## 0.2.0 — 2026-10-27

- CycleTimeDrilldown이 Saved View를 지원한다(`features.savedView`, 조건 6종과 page 키 6종 선언, #1011).

## 0.1.0 — 2026-10-27

- 초기 기록: ProductivityOverview, CycleTimeDrilldown, ExecutionDetail, ChartCatalog와 Wafer Journey 계획.
