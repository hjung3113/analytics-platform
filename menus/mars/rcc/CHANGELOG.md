# @ap/menu-rcc 변경 기록

내부 버전이며 발행하지 않는다. SDK 범위는 package.json의 ap.sdk를 따른다.

## 0.2.5 — 2026-11-23

- (#2755) Step 단계 «Step × 설비» 히트맵 패널이 Step 행 수와 x축이 다 보이는 높이 아래로 줄지 않는다(저장된 배치 포함). 막대 패널 높이 계산은 SDK `rowPitchChartHeight`를 쓴다.

## 0.2.4 — 2026-11-23

- (#2700) RCC 드릴 경로 표시명, 개발용 화면 설명, 히트맵 기준 범례, 비교 보류 설비 행 문구(Layer·Step 막대), 현재 Step 표식, 실행 ID 한 줄 표시와 페이지 스크롤, PPID 결과 중복 열 제거, 비교 묶음 용어 적용.

## 0.2.3 — 2026-11-22

- (#2496) RCC 시간 비교 화면(합성 데이터, mock 개발 빌드 한정): 공용 조회 창과 조건 저장, 비교 묶음 → Layer → Step → Lot/Wafer 드릴, Step 막대 끝 실제 L1 총시간 표식, 히트맵 비교 보류와 선택 셀 강조.
