# @ap/menu-hw-time 변경 기록

내부 버전이며 발행하지 않는다. SDK 범위는 package.json의 ap.sdk를 따른다.


## 0.6.0 — 2026-11-17

- S0 선언 위에 판정 도넛·초과 건수 파레토·설비별 일 평균 히트맵·HTM 기준 감사 이력 추가, 판정 상세·날짜 셀 실행의 URL 연동, 선택 판정 건수·비율/명시적 해제 및 Context 변경 시 날짜 초기화, 단계별 히트맵 값 적용. Finding/VOC 생성 링크 및 판정별 셀 채움색은 계약/SDK 미지원으로 미구현 (#2431).
- 고정 아래 줄의 판정 도넛에 최소 높이·패널 내부 스크롤 적용, HTM 추세와 같은 판정 색상 사용 (#2431).

## 0.5.5 — 2026-11-17

- HW Time 합성 회차를 HTM 안쪽 중심 분포와 소수의 상하한 이탈로 조정. 상한 바로 뒤 꼬리와 드문 큰 값 2개, 설비·Module별 혼합 판정 유지 (#2429).

## 0.5.4 — 2026-11-17

- 전체 회차를 서버에서 0.25초 구간으로 집계하는 분포 히스토그램 패널 추가: 드릴·지점 대상, HTM 상하한·기준 밖 구간 상태, 패널 추가·고정 지원 (#2429).

## 0.5.3 — 2026-11-17

- 기존 추가 패널 6종을 S0 선언 데이터로 이행: 조회 입력·표시 입력(context/page)·동작별 page 출력·메뉴별 데이터 단위·endpoint·선택 쓸 수 있는 조건, 메뉴 index에서 공개. 모양과 요청 경계는 그대로 (#2431, #2433).

## 0.5.2 — 2026-11-17

- HTM 추세를 일별 평균 범주축과 일별 상한 초과·하한 미달 설비 수 누적 막대로 표시. 2일 미만은 한 줄 안내, 빈 HTM 경계 캡션 제거 (#2426).

## 0.5.1 — 2026-11-16

- Module·Motion 독립 체크와 Module 타입의 Motion 전체 체크 적용, 패널 추가를 작업 영역 도구줄로 이동, 단계별 차트 제목을 패널 탭에, 현재 패널 옵션·변경 칩을 차트 위 한 줄로 (#2399, #2416).

## 0.5.0 — 2026-11-16

- Module 타입 → Motion → Module 네 단계, 이전/현재 차트와 계층, 패널별 옵션·추가·URL 고정, 지점 HTM 추세 연결 (#2399).

## 0.4.3 — 2026-11-16

- 분포·추세의 HTM 기준 띠와 선·범례 색 통일, 기준 밖만 표식하는 규칙 공통화 (#2362).

## 0.4.2 — 2026-11-16

- 패널별 차트 배치 선언: 설비 × Module은 위 범례·상시 도구, Module별 Motion 구성과 분포는 아래 범례·합성/판정/부분 데이터 캡션·상시 도구, 추세는 오른쪽 세로 범례·hover/focus 도구. 소유자가 선택한 배치 적용 (#2372).

## 0.4.1 — 2026-11-16

- 숨김 호환 항목 4개(`hw-time-steps|compare|overview|table`) 제거. 옛 id는 앱 조립의 `retiredMenus`로 `hw-time`에 이어지고 옛 주소·보드 칸·즐겨찾기·최근 방문이 이 화면을 연다 (#2330).

## 0.4.0 — 2026-11-16

- HW Time을 연결 패널 일곱 개의 단일 분석 화면으로 통합. View·분포·추세 전환 탭 제거, URL 드릴과 옛 주소·보드 호환 유지 (#2328).
- 필터·히트맵·누적 막대·Motion 표·분포·추세·원시 표를 SDK 작업 영역에 배치. Inspector 시작 위치 옵션, 패널별 독립 필터, 서버 판정과 차분한 산점도 표시 (#2329).

## 0.3.3 — 2026-11-14

- 추세 응답 행 수·Scope 밖 행 안내, 표 focus 검증·드릴 초기화, 조회 기간 안의 일 추세 (#2077).

## 0.3.2 — 2026-11-14

- 화면 문구를 긍정형 개조식으로 정리하고 줄표·가능 표현을 줄임 (#1996).

## 0.3.1 — 2026-11-14

- HW Time 값은 합성이라 Job 축이 없으므로 `ppid`·`recipe`를 `unsupported`로 선언한다(조건 막대가 미적용으로 표시). 조회 문은 그대로다(#2072).

## 0.3.0 — 2026-11-09

- 저장값이 없는 `HW Time 비교`가 SDK 기본값 전환(`sdk-v0.33.0`, ADR-0130)으로 아래로 쌓기로 시작한다. 줄이 하나라 첫 화면에 페이지 스크롤바는 없고 아래에 놓기 띠가 생긴다. 저장된 화면 맞춤은 그대로이고, `HW Time 개요`는 이미 쌓기로 시작했다.(#701)

## 0.2.2 — 2026-11-05

- 비교 화면의 보이는 패널 제목(Module 구성·Motion 상세)과 위젯 이름이 이전 결과가 보이는 동안 그 결과의 Module·Motion을 쓴다.(#1365 수정 라운드 2)

## 0.2.1 — 2026-11-05

- 단계별·비교·개요·표의 제목·요약·빈 상태 문구가 보존된 결과를 불러온 때의 Module·Motion을 쓴다. 이전 결과가 남아 있는 동안 차트 구간·범례의 드릴은 동작하지 않는다(새 경로에 이전 값을 쓰지 않게). 비교 화면의 구성 패널도 같다.(#1365 수정 라운드)

## 0.2.0 — 2026-11-05

- 단계별·비교·개요·표의 드릴/레벨 선택과 추세 행 선택을 바꾸면 이전 결과가 새 결과가 올 때까지 남는다(공유 조회 훅 `useHwTimeLevel`·`useHwTimeTrend`, #1365, [ADR-0114](../../../docs/adr/0114-opt-in-keep-previous-for-page-input-params.md)). 기간·Scope를 바꾸면 이전처럼 가려진다.

## 0.1.4 — 2026-11-01

- 4개 화면(단계별·비교·개요·표)에서 `density="compact"` 선언을 걷는다 — SDK 기본 밀도가 compact로 바뀌었다(#1217, 06 §12).

## 0.1.3 — 2026-11-01

- 단계 요약 실패 박스가 같은 응답의 표와 한 그룹(배너 하나 + 간결 상태)으로 묶인다(#1175).

## 0.1.2 — 2026-10-31

- Inspector 분석 대상(과 비교의 Module 없는 범례)이 빈 결과·오류 응답을 따라 문구를 바꾼다(#1158).

## 0.1.1 — 2026-10-30

- 승인 B의 compact 간격·막대 호버 완화·native Dock 도킹 표시 적용(#1141).
