## 0.11.12 — 2026-11-24

- (#2733) 분석 선택 칩에 설비 이름을 표시

## 0.11.11 — 2026-11-24

- (#2796) 사용 중단된 `chart-purple`을 같은 값의 `chart-series-3`으로 바꿨습니다(화면 불변). 추이 색 목록의 7번째 자리는 3번째와 같은 토큰이 되지 않도록 `chart-green`으로 바꿨습니다(지금 추이는 한 줄만 그려 보이지 않음).

## 0.11.10 — 2026-11-24

- (#2733) 출처에 선택 설비가 없으면 원본 표의 설비 필터를 해제

## 0.11.9 — 2026-11-24

- (#2732) Module별 Motion 차트의 지점 동작에서 원본 표 필터에 설비를 추가하거나 빼고 필터를 해제할 수 있다. 원본 표 탭에 결과 행 수를 표시한다.

## 0.11.8 — 2026-11-23

- (#2770) 조회 이력 줄의 드릴 단계를 SDK `historyDrill`이 넣는다. 보이는 글은 그대로다.

## 0.11.7 — 2026-11-22

- (#2691) 조회 이력 줄이 드릴 단계·고른 Module/Motion·판정·날짜를 보인다. 드릴·필터만 다른 두 이력이 같은 글로 보이지 않는다.

## 0.11.6 — 2026-11-18

- (#2490) 빌려준 추세에서 비교 설비별 동작시간과 공통 HTM 기준을 표시한다. Configuration에서 연 추세의 범례에는 비교 행렬의 설비 이름이 표시된다.

## 0.11.5 — 2026-11-18

- (#2490) 다른 메뉴에서 선택한 설비 한 대의 Motion 일 평균과 HTM 상·하한을 볼 수 있도록 추세 패널을 제공.

## 0.11.4 — 2026-11-18

- (#2503) 공통 조회 막대에서 조건을 모아 적용하고 저장된 뷰로 복원. 기간 없는 기존 조건 링크도 조건을 유지한 채 열며, 메뉴 뷰에 원본 표 열 묶음 포함.

## 0.11.3 — 2026-11-18

- «이 패널 만든 방법»을 SDK 패널 레시피(`panelRecipe`·`PanelRecipeBack`·`PanelRecipeFrame`)로 옮김. 레시피는 Registry 패널에서 만들고, 메뉴는 키 이름표·모양·코드 줄 수만 넘김. 화면 변화 없음 (#2471).
- 원문 표의 «컬럼» 팝오버에서 열 묶음 만들기·이름 바꾸기·구성 변경·풀기와 사용자별 저장 지원 (#2481, SDK 선택 옵션).

## 0.11.2 — 2026-11-17

- «이 패널 만든 방법» 뒷면과 원문 줄 수 모델을 패널을 뒤집을 때만 받음, 화면 청크에서 원문 7개 제외 (v0.40 review-quality Q3).
- 판정·날짜 해제 칩: X 아이콘, «판정 상한 초과 필터 해제» 같은 접근 이름, 지운 뒤 페이지 대체 위치로 포커스 (v0.40 review-quality Q5).

## 0.11.1 — 2026-11-17

- 메뉴 manifest의 panels로 패널을 등록하고 Kernel 입력·가용성 도우미로 패널 추가 목록 생성 (#2433).

## 0.11.0 — 2026-11-17

- 모든 선언 패널의 ⋯ 메뉴에 «이 패널 만든 방법»: 선언·SDK 조각·플랫폼 기능과 집계 기준을 패널 뒷면에 표시 (#2432).
- 패널별 CSV 지원에 맞춰 제공 수를 집계하고, 설명 본문 키보드 접근 및 앞면 복귀 포커스 보장 (#2432).

## 0.10.0 — 2026-11-17

- 작업 영역의 기본 패널을 제외한 모든 패널에 왼쪽 접기 레일용 아이콘 선언 (#2435).

## 0.9.0 — 2026-11-17

- 현재 단계 막대의 패널 옵션(정렬·최소·최대·시작 맞춤)을 차트 도구 줄 왼쪽으로 옮김: 옵션 줄과 바뀐 옵션 칩 줄을 없애 막대 앞 컨트롤이 112px→76px (#2459, 확정 변형 B).

## 0.8.0 — 2026-11-17

## 0.7.1 — 2026-11-17

- 분포 히스토그램이 산점도와 같은 회차 모집단을 읽음: 판정·날짜 패널 연결(`verdict`·`date`)을 조회 입력과 endpoint 키로 받음 (#2429, #2431).

## 0.7.0 — 2026-11-17

- 두 히트맵에 서버 판정별 채움·범례, 도넛 URL 선택·중앙 요약 복원, HTM 변경 이력의 번역 라벨·초 단위·합성 작업자 이름 적용. 설비 × 날짜 히트맵도 행 최소 높이·내부 스크롤·판정 테두리 전용. 합성 회차의 설비·Module별 결정적 편차와 Motion별 하한 미달 예시를 더해 값·판정 분산 개선 (#2431, #2449).

## 0.6.1 — 2026-11-17

- 히트맵 행 최소 높이·내부 스크롤과 상태 테두리 전용 표시, 도넛 높이 맞춤, 결정적 Module·Motion 초과 건수 꼬리 분포, 계약 없는 Finding/VOC 단추 숨김, 추가 패널의 주 차트 묶음 탭 배치로 기본 행 높이 보존 (#2431).

## 0.6.0 — 2026-11-17

- S0 선언 위에 판정 도넛·초과 건수 파레토·설비별 일 평균 히트맵·HTM 기준 감사 이력 추가, 판정 상세·날짜 셀 실행의 URL 연동, 선택 판정 건수·비율/명시적 해제 및 Context 변경 시 날짜 초기화, 단계별 히트맵 값 적용. Finding/VOC 생성 링크 및 판정별 셀 채움색은 계약/SDK 미지원으로 미구현 (#2431).
- 고정 아래 줄의 판정 도넛에 최소 높이·패널 내부 스크롤 적용, HTM 추세와 같은 판정 색상 사용 (#2431).

## 0.5.5 — 2026-11-17

## 0.5.4 — 2026-11-17

## 0.5.3 — 2026-11-17

## 0.5.2 — 2026-11-17

## 0.4.3 — 2026-11-16

## 0.4.2 — 2026-11-16

## 0.4.0 — 2026-11-16

- 필터·히트맵·누적 막대·Motion 표·분포·추세·원시 표를 SDK 작업 영역에 배치. Inspector 시작 위치 옵션, 패널별 독립 필터, 서버 판정과 차분한 산점도 표시 (#2329).

## 0.3.0 — 2026-11-09

- 저장값이 없는 `HW Time 비교`가 SDK 기본값 전환(`sdk-v0.33.0`, ADR-0130)으로 아래로 쌓기로 시작한다. 줄이 하나라 첫 화면에 페이지 스크롤바는 없고 아래에 놓기 띠가 생긴다. 저장된 화면 맞춤은 그대로이고, `HW Time 개요`는 이미 쌓기로 시작했다.(#701)

## 0.2.2 — 2026-11-05

- 비교 화면의 보이는 패널 제목(Module 구성·Motion 상세)과 위젯 이름이 이전 결과가 보이는 동안 그 결과의 Module·Motion을 쓴다.(#1365 수정 라운드 2)

## 0.2.1 — 2026-11-05

- 단계별·비교·개요·표의 제목·요약·빈 상태 문구가 보존된 결과를 불러온 때의 Module·Motion을 쓴다. 이전 결과가 남아 있는 동안 차트 구간·범례의 드릴은 동작하지 않는다(새 경로에 이전 값을 쓰지 않게). 비교 화면의 구성 패널도 같다.(#1365 수정 라운드)

## 0.2.0 — 2026-11-05
