# @ap/menu-hw-time 변경 기록

내부 버전이며 발행하지 않는다. SDK 범위는 package.json의 ap.sdk를 따른다.

## 0.3.0 — 2026-11-09

- 저장값이 없는 `HW Time 비교`가 SDK 기본값 전환(`sdk-v0.33.0`, ADR-0130)으로 아래로 쌓기로 시작한다. 줄이 하나라 첫 화면에 페이지 스크롤바는 없고 아래에 놓기 띠가 생긴다. 저장된 화면 맞춤은 그대로이고, `HW Time 개요`는 이미 쌓기로 시작했다.(#701)

## 0.2.2 — 2026-11-05

- 비교 화면의 보이는 패널 제목(Module 구성·Motion 상세)과 위젯 이름이 이전 결과가 보이는 동안 그 결과의 Module·Motion을 쓴다.(#1365 수정 라운드 2)

## 0.2.1 — 2026-11-05

- 단계별·비교·개요·표의 제목·요약·빈 상태 문구가 보존된 결과를 불러온 때의 Module·Motion을 쓴다. 이전 결과가 남아 있는 동안 차트 구간·범례의 드릴은 동작하지 않는다(새 경로에 이전 값을 쓰지 않게). 비교 화면의 구성 패널도 같다.(#1365 수정 라운드)

## 0.2.0 — 2026-11-05

- 단계별·비교·개요·표의 드릴/레벨 선택과 추세 행 선택을 바꾸면 이전 결과가 새 결과가 올 때까지 남는다(공유 조회 훅 `useHwTimeLevel`·`useHwTimeTrend`, #1365, [ADR-0114](../../../docs/adr/0114-opt-in-keep-previous-for-page-input-params.md)). 기간·Scope를 바꾸면 이전처럼 가려진다.

## 0.1.4 — 2026-11-01

- 4개 화면(단계별·비교·개요·표)에서 `density="compact"` 선언을 걷는다 — SDK 기본 밀도가 compact로 바뀌었다(#1217, 06 §12).

## 0.1.3 — 2026-11-01

- 단계 요약 실패 박스가 같은 응답의 표와 한 그룹(배너 하나 + 간결 상태)으로 묶인다(#1175).

## 0.1.2 — 2026-10-31

- Inspector 분석 대상(과 비교의 Module 없는 범례)이 빈 결과·오류 응답을 따라 문구를 바꾼다(#1158).

## 0.1.1 — 2026-10-30

- 승인 B의 compact 간격·막대 호버 완화·native Dock 도킹 표시 적용(#1141).

## 0.1.0 — 2026-10-27

- 초기 기록: HW Time 단계별, 비교, 개요, 표.
