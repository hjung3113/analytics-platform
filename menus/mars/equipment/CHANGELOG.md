# @ap/menu-equipment 변경 기록

내부 버전이며 발행하지 않는다. SDK 범위는 package.json의 ap.sdk를 따른다.

## 0.2.1 — 2026-11-01

- 필터 줄의 고정 버튼 순서가 열 순서(Maker, 상태)가 아니라 상태 → Maker로 나온다. 주소가 틀렸을 때의 안내 제목은 틀린 것(필터만, 정렬·페이지만, 둘 다)에 맞게 나온다 (#1217).

## 0.2.0 — 2026-11-01

- 설비 목록의 왼쪽 필터 패널이 없어진다. 상태와 Maker는 표 위 필터 줄의 고정 버튼으로, 나머지 열(라인·Model·변경자·유효 시작·유효 종료일)은 「+ 필터」와 머리글 깔때기로 건다. 모든 조건은 주소에 보이지 않고(새로고침·뒤로/앞으로·저장된 보기·「현재 조건 공유」 링크에 실린다) 하나의 `filter` 키로 다룬다.
- 설비 ID 검색(`q`)은 표 도구줄의 검색 칸으로 옮긴다. 입력은 Enter로 적용하고, 비우면 바로 풀린다.
- 옛 링크 `?status=`·`?maker=`는 한 릴리스 동안 같은 결과를 보이고, 열자마자 주소에서 사라진다. 서버(mock)는 선언하지 않은 필드·연산자를 `error`로 거절하고, 목록·내보내기 요청에서 `status`·`maker` 파라미터는 없어진다 (#1217).

## 0.1.3 — 2026-11-01

- 설비 목록 표 위에 「그룹」 선택이 생긴다: 라인으로 묶으면 그룹 머리 행이 라인 이름과 필터 결과 전체 기준 행 수를 보이고, 접고 펼 수 있다. 내보내기는 그룹과 상관없이 평평한 행 그대로다 (#556).

## 0.1.2 — 2026-11-01

- 설비 목록 머리글에 열 필터가 생긴다: 라인(선택), Model·변경자(글자), 유효 시작·유효 종료일(날짜 범위). 적용한 필터는 표 위 칩으로 보이고 내보내기에도 반영된다. 상태는 기존대로 왼쪽 필터 패널에서만 거른다 (#556).

## 0.1.1 — 2026-10-31

- 설비 상세 신뢰 표시가 좁은 상세 서랍에서 상태 점·문구·정보 아이콘이 한 흐름으로 줄바꿈하며, 점과 아이콘이 별도 줄에 고립되지 않는다 (#1167).
