# 백로그 — 이슈로 올리지 않은 것

우선순위가 낮거나 수요가 확인되지 않은 일이다. 착수하려면 먼저 GitHub 이슈로 올리고 이 줄을 지운다.

## 작은 후속 (확인된 것)

- **구현 안 함 — `tableFit` MutationObserver의 rebind를 rAF 하나로(#823 4번):** `packages/components/src/tableFit.ts:104-143`. 이유: MutationObserver 콜백은 이미 마이크로태스크마다 레코드를 묶어 1회 불리고 viewport 안 변경도 거른다(#823 재검증). 남는 이득은 한 프레임 안 여러 마이크로태스크의 중복뿐인데, 관찰 콜백이 동기로 돈다고 가정하는 표 테스트(`fireObservers`)를 바꿔야 한다. 다시 볼 조건: 표가 둘 이상인 화면에서 프로파일러로 `rebind`/`measure` 강제 레이아웃이 프레임 예산을 넘는 것이 측정될 때.

- **구현 안 함 — 미측정 계열을 숨겨도 남는 메뉴 부제의 미측정 행 수(#580 580g UX 메모):** HW Time `미측정 값이 있는 행 N개 — …` 부제는 미측정 계열(예: PM3)을 숨기거나 모두 숨겨도 그대로다. 이유: 숨김 상태는 각 페이지가 가지고 `StackPanel`에 `visibleSeriesIds`로 넘기지만, 개수는 응답 행 전체 기준으로 센다. 보이는 계열 기준으로 바꾸면 숨김 토글마다 부제가 달라지고 그 규칙(모두 숨김일 때 등)을 새로 정해야 한다. 표시만 어긋나고 값은 틀리지 않는다. 다시 여는 조건: 사용자가 이 어긋남을 보고하거나, 개수 문구가 Frame으로 옮겨질 때.
