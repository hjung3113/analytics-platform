## 그 다음 — FeedbackOps 2단계 (M5, 지도 #213)

통합 깊이 A: 화면은 플랫폼 메뉴 패키지로 옮기고 백엔드는 FeedbackOps 도메인 API로 유지한다([ADR-0018](../docs/adr/0018-feedbackops-stage2-screens-into-platform-menus.md)). 자리는 별도 피드백 공간이 아니라 공간별 협업 진입 + 전체 허브다(ADR-0026). 메뉴 화면을 여러 개 연속으로 옮기는 일이라 착수 전에 사용자에게 범위를 확인한다.

| 순서 | 할 일 | 상태 |
| --- | --- | --- |
| 1 | 범위 확인(사용자) | 대기 |
| 2 | 남은 결정을 `ready-for-human` 이슈로 나눔: Scope↔Managed System, 세션 공유(#150 의존), 권한 매핑, 공간별 협업 진입의 메뉴 구성과 전체 허브 형태(독립 공간 / 전역 경로), 독립 앱 존속, 알림·감사 통합 | 이슈 없음 |
| 3 | 결정 없이 할 수 있는 플랫폼 선행을 이슈로: 메뉴 조회 포트 쓰기 계약, Workflow 레이아웃(06 §12), 셸 알림 슬롯 | 이슈 없음 |
| 4 | 프로토타입: 사이드바 협업 진입(현재 시스템 범위) + 전체 허브 + 대표 화면(VOC 분류 목록+상세, Task 보드, 설문) → 컨펌 | 3과 #249 2단계 뒤 |
| 5 | 이전: 읽기 화면 → 쓰기 → Task·Milestone → 설문 | 4 뒤 |

거친 추정(2026-09-26 인터뷰, 깊이 A 결정 전 값, 일정 승인 아님): 셸 편입 4~8주.
