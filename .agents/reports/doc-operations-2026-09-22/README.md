# analytics-platform 문서 운영 체계 설계

2026-09-22 조사·권고. **기존 경로를 우선 유지하고, 계약 단위의 원본·상태·소비 관계와 작업별 구현 증거를 연결한다.** 폴더 재분류, 새 문서 포털, 전면 frontmatter, RAG 도입을 먼저 하지 않는다. 이 패키지는 제품 결정·기술 채택·구현 승인이 아니며 실제 문서 이행도 아직 수행하지 않았다.

> 후속 상태 안내(2026-09-23): 아래는 조사 당시의 제안·원본 위치·미결 상태를 보존한 기록이다. 이후 M1–M4와 후속 축약을 적용했다. 현재 책임은 [INDEX](../../../docs/INDEX.md), 진행 상태·후속 작업은 [HANDOFF](../../../HANDOFF.md), 이관 보존 근거는 [M4 기록](../m4-document-consolidation-2026-09-23.md)을 따른다. 아래의 “아직 적용하지 않았다”와 05 R/H 원본 표시는 조사 시점에 한정한다. `validate.py`는 당시 snapshot 비교용이며 현재 회귀 검사로 재실행해 `validation.json`을 덮어쓰지 않는다.

## 다음 에이전트가 먼저 알아야 할 것

- 먼저 현재 AGENTS/Git/INDEX를 다시 읽는다. 이 보고서 이후 원본이 달라졌으면 영향 부분만 갱신한다.
- 06은 전역 UX·Context·URL·Scope·메뉴 확장의 원본, DESIGN은 시각·render 상호작용 원본이다. **현재 05는 R/H 등 상세 정책도 소유**하므로 단순 색인화하며 삭제하면 안 된다.
- 파일 안의 Decided/Candidate/Open을 분리한다. 설계 결정, 구현 존재, 검증 증거는 다른 상태다. 체크박스나 모델 동의로 합치지 않는다.
- 첫 이행은 M1: INDEX/03/04/07의 길찾기와 확정 메커니즘의 오래된 Open 표현 정정이다. 06 본문·숫자·기술 선택·서브모듈은 변경 대상이 아니다.
- 토론에서는 작은 원본 인접 소비자 포인터 시범에 조건부 수렴했다. 영구 운영 위치는 아직 미검증이므로 I7 및 실제 변경에서 평가한다. 둘을 중복 원본으로 만들지 않는다.

## 실행 경계

시작 HEAD `2d6fe5ad9f9d610e45ba028930f7c2effdad9d4a`, 시작 Git clean. 모든 새 산출물은 이 디렉터리 안에 있다. 원본 471개 해시와 FeedbackOps gitlink를 대조했다. commit/push·제품 코드·기존 문서 이동/재작성·서브모듈 변경은 하지 않았다.

주 에이전트 + **Grok 4.6 High + GLM 5.3 Max**가 실제 별도 런타임으로 토론했다. Luna Max는 조사·별도 샘플 검토를 보조했다. [실행 기록](discussion/EXECUTION.md)에 모델 확인·호출 수단·실패 후 수정·독립성 조건을 남겼다. 지정 모델의 역할을 다른 모델이 연기하지 않았다.

## 후속 기록: 사용자 요청에 따른 커밋·HANDOFF 갱신

조사 완료 후 사용자가 산출물 커밋과 다음 세션 실행을 위한 HANDOFF 갱신을 요청했다. 루트 HANDOFF 상단에 M0/M1 시작 경로·네 파일 범위·보존/검증 조건을 추가하고 기존 기록은 보존했다. 위 ‘원본 무변경·미커밋’ 서술과 validation.json은 **이 후속 작업 전 조사 종료 시점**의 기록이다. 조사 snapshot은 갱신하지 않는다. 이후 validator 재실행은 HANDOFF drift를 보고하고 validation.json을 덮어쓰므로, 새 작업 검증은 별도 기록에 남긴다. 제품 문서 이행은 아직 수행하지 않았다.
