분석 플랫폼 용어

소개 페이지에서 사용하는 용어를 정의합니다.

업무 시스템
플랫폼 위의 독립 업무 단위로, 고유 메뉴와 업무 객체를 소유합니다. 근거 L114
메뉴
Menu Registry에 선언하는 업무 화면으로, 이름·경로·권한·기능을 가집니다. 근거 L114
본 화면
메뉴를 눌러 여는 보통의 화면이며, URL 하나와 분석 Context 하나를 가집니다. 근거 L114
분석 보드
여러 분석 화면을 나란히 두고 비교하는 셸 제공 화면으로, 업무 시스템과 Page Archetype에 속하지 않습니다. 근거 L114
시트
분석 보드 아래의 탭 하나로, 칸의 배치와 화면들을 가집니다. 근거 L114
칸
시트의 그리드 한 자리로, 메뉴 화면 하나와 그 화면의 분석 Context·page 상태를 가집니다. 근거 L114
분석 Context
화면 하나가 따르는 분석 조건 전체로, 목적지 객체 ID와 구분합니다. 근거 L114
기본 조건
새 칸이 처음 받는 분석 Context이며, 복사로 시작하고 이후에는 상속하지 않습니다. 근거 L114
딥링크
조건과 화면 위치를 URL에 담아 해당 화면을 다시 여는 링크입니다. 근거 L114
Site
공장이 위치한 최상위 물리 조직 단위이며, 여러 room_name과 Line을 포함합니다. 근거 L114
공정 (room_name)
설비가 속한 공정의 이름(예: PHOTO, ETCH)이자 Site 안의 권한·조회 범위 기준입니다. 근거 L114
Line
Site 안의 생산 라인으로, room_name과 교차하는 독립 조회축입니다. 근거 L114
Scope
한 번의 조회에 선택하는 접근·조회 범위로, Site 안의 room_name 기준으로 부여되고 서버가 재검증합니다. 근거 L114
Audit
행위·대상·시각과 변경 내용을 공통 형식으로 기록하고 조회하는 감사 이력입니다. 근거 L114
추적 번호
화면 오류와 오류 보고를 연결해 확인하는 Correlation ID입니다. 근거 L114
VOC
FeedbackOps가 다루는 사용자 의견·개선 요청으로, 관련 업무 시스템과 화면 링크를 함께 전달할 수 있습니다. 근거 L114
FeedbackOps Task
제품 개선·개발 요청을 처리하는 공통 협업 객체입니다. 업무 객체와는 이름이 비슷해도 다른 객체이며 관계만 링크합니다. 근거 L114
